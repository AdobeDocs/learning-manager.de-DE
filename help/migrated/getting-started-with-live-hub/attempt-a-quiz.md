# Quiz testen

Tests helfen Ihnen, Ihr Verständnis des Sitzungsinhalts zu bewerten. Wenn ein Kursleiter ein Quiz startet, wird es auf der Sitzungsoberfläche angezeigt, wo Sie Fragen beantworten und Ihre Antworten senden können.

Ihre Antworten werden automatisch gespeichert, wenn Sie das Quiz durchlaufen. Wenn der Kursleiter ein Zeitlimit festlegt, zeigt ein Timer die verbleibende Zeit an. Nachdem Sie das Quiz eingereicht haben, können Sie abhängig von den Einstellungen des Veranstalters möglicherweise Ihr Ergebnis anzeigen und richtige und falsche Antworten überprüfen.

In diesem Artikel wird erläutert, wie Sie ein Quiz absolvieren, Ihre Antworten senden und Ihre Ergebnisse überprüfen.

## Test starten

Sie können das Quiz sofort starten und während der Sitzung auf die Fragen antworten.

So wiederholen Sie ein Quiz:

1. Wählen Sie **Test starten**, wenn das Quiz angezeigt wird.

1. Wählen Sie Ihre Antwort aus.

1. Wählen Sie **Senden**. Ihre Antworten werden zur Bewertung weitergeleitet.

Wenn ein Zeitlimit festgelegt wurde, wird die verbleibende Zeit angezeigt, während Sie das Quiz absolvieren. Sie können je nach Bedarf zwischen den Fragen wechseln, bevor Sie sie einreichen.

Bildschirm mit ![Quizanweisungen](assets/quiz-instructions-screen.png)
*Die Registerkarte &quot;Quiz&quot; zeigt die Anweisungen an, bevor das Quiz gestartet wird.*

## Quizversuch überprüfen

Nach dem Senden können Sie eine Zusammenfassung Ihres Versuchs überprüfen. Die Zusammenfassung zeigt die Anzahl der Fragen an, die Sie gestellt haben, und Ihren Status zum Abschluss des Quiz.

Wenn diese Option vom Kursleiter aktiviert wurde, können Sie Ihre Antworten auch nach der Übermittlung überprüfen. Dadurch können Sie Ihr Ergebnis anzeigen, ausgewählte Antworten anzeigen und richtige und falsche Antworten identifizieren.

![Punktzahl für Quizüberprüfung](assets/quiz-review-score.png)
*Wählen Sie Punktzahl anzeigen aus, um Ihre richtigen und falschen Antworten anzuzeigen.*
