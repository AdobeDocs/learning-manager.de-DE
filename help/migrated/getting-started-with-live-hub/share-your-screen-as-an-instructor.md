# Bildschirm als Kursleiter freigeben

Mit der Bildschirmfreigabe können Sie den Teilnehmern während einer Live Hub-Sitzung Inhalte von Ihrem Gerät präsentieren. Geben Sie eine Browser-Registerkarte, ein Anwendungsfenster oder Ihren gesamten Bildschirm frei, um Workflows zu demonstrieren, Präsentationen bereitzustellen und Teilnehmer durch Aufgaben in Echtzeit zu führen.

Sie können Präsentationen verbessern, indem Sie bis zu zwei Inhalte nebeneinander in der geteilten Ansicht anzeigen, ein Whiteboard neben freigegebenen Inhalten verwenden und wichtige Informationen durch Anmerkungen direkt auf dem Bildschirm hervorheben. Sie können Teilnehmern auch die Freigabe ihrer Bildschirme ermöglichen, während Sie die Kontrolle über die Sitzung behalten.

In diesem Artikel wird erläutert, wie Sie Ihren Bildschirm freigeben, Inhalte kommentieren, die geteilte Ansicht verwenden und die Bildschirmfreigabe der Teilnehmer im Live Hub verwalten.

## Freigeben des Bildschirms in einer Sitzung

Sie können die Bildschirmfreigabe während einer Sitzung starten, um allen Teilnehmern Inhalte in Echtzeit zu präsentieren. Auf diese Weise können Sie Anwendungen demonstrieren, Workflows durchlaufen oder Präsentationen direkt von Ihrem Gerät aus bereitstellen.

Führen Sie die folgenden Schritte aus, um Ihren Bildschirm freizugeben:

1. Wählen Sie in der Steuerungsleiste ![Bildschirm freigeben](./assets/share-screen-icon.svg) aus. Es wird ein Popupfenster angezeigt.

1. Wählen Sie eine der folgenden Optionen aus:

   1. **Registerkarte &quot;Chrome&quot;**: Geben Sie eine Browser-Registerkarte frei.

   1. **Fenster**: Freigeben einer bestimmten Anwendung.

   1. **Gesamter Bildschirm**: Den Vollbildschirm freigeben.

   ![Option &quot;Gesamten Bildschirm freigeben&quot;](assets/share-entire-screen-option.png)
   *Popup-Fenster für Bildschirmfreigabe mit mehreren Optionen für die Bildschirmfreigabe.*

1. (Optional) Aktivieren Sie **Audio der Registerkarte &quot;**&quot; ebenfalls freigeben, um Audio von der freigegebenen Registerkarte einzuschließen.

1. Wählen Sie den Inhalt aus, den Sie freigeben möchten.

1. Wählen Sie **Freigeben** aus. Der ausgewählte Inhalt wird allen Teilnehmern angezeigt.

Sie können während einer Sitzung bis zu zwei Inhalte freigeben. Wenn zusätzlicher Inhalt freigegeben wird, passt sich das Layout automatisch an, um ihn zusammen anzuzeigen.

### Bildschirmfreigabe beenden

Um die Bildschirmfreigabe zu beenden, wählen Sie **Bildschirmfreigabe beenden** in der Oberfläche des freigegebenen Bildschirms.

![Steuerung der Bildschirmfreigabe beenden](assets/stop-screen-sharing-control.png)
*Steuerungsleiste, die die Option zum Beenden der Bildschirmfreigabe anzeigt.*

Die Bildschirmfreigabe in der Sitzung wird beendet und der freigegebene Inhalt wird aus der Raumoberfläche entfernt.

## Mehrere Inhalte in einer Sitzung freigeben

Virtuelles Klassenzimmer unterstützt die geteilte Ansicht, wenn mehrere Inhaltstypen während einer Sitzung freigegeben werden. Dadurch können Kursleiter mehrere Inhaltstypen gleichzeitig präsentieren, z. B. eine Bildschirmfreigabe, ein Whiteboard oder ein Interaktionsfenster.

### Funktionsweise der geteilten Ansicht

Wenn mehrere Inhalte aktiv sind:

* Es können maximal zwei Inhalte gleichzeitig angezeigt werden.

* Auf der Hauptbühne wird jeweils ein Inhalt angezeigt.

* Der andere Inhalt wird in einer sekundären Ansicht angezeigt.

* Wenn neuer Inhalt freigegeben wird, wird vorhandener Inhalt möglicherweise in die sekundäre Ansicht verschoben.

>[!NOTE]
>
> Interaktionsfenster, z. B. Umfragen, werden priorisiert und zuerst in der geteilten Ansicht angezeigt.

### Zur Einzelansicht wechseln

Wenn mehrere Inhalte angezeigt werden, können Kursleiter zu einem einzelnen Inhalt wechseln.

Wechseln zu einer einzelnen Ansicht:

1. Wählen Sie den Inhalt aus, der in den Fokus rücken soll.

1. Wählen Sie **Maximieren**. Der ausgewählte Inhalt wird auf der Hauptbühne angezeigt, während der verbleibende Inhalt in eine sekundäre Ansicht verschoben wird.

## Bildschirmfreigabe mit einem Whiteboard verwenden

Sie können die Bildschirmfreigabe während einer Sitzung neben einem Whiteboard ausführen, um Inhalte beim Hinzufügen von Erklärungen oder Anmerkungen anzuzeigen.

Wenn ein Whiteboard während einer aktiven Bildschirmfreigabe freigegeben wird oder wenn die Bildschirmfreigabe startet, während ein Whiteboard bereits aktiv ist, wechselt die Sitzung automatisch zur geteilten Ansicht.

So verwenden Sie die Bildschirmfreigabe mit einem Whiteboard:

1. Den Bildschirm freigeben.

1. Wählen Sie in der Steuerungsleiste das Whiteboard-Symbol aus.

1. Wählen Sie **Whiteboard freigeben**. Beide Inhalte werden in der geteilten Ansicht angezeigt.

   ![Geteilte Ansicht für Whiteboard-Bildschirmfreigabe](assets/screen-share-whiteboard-split-view.png)
   *Live-Hub-Oberfläche, die eine geteilte Ansicht mit dem Whiteboard auf der linken Seite und freigegebenen Inhalten auf der rechten Seite zeigt.*

So wechseln Sie den Fokus zwischen Whiteboard und freigegebenem Bildschirm:

1. Wählen Sie den Inhalt aus, den Sie anzeigen möchten.

1. Wählen Sie **Maximieren**. Der ausgewählte Inhalt wird in die Hauptbühne verschoben. Der andere Inhalt wird in eine sekundäre Ansicht verschoben.

   ![Sekundäre Ansicht für Bildschirmfreigabe](assets/screen-share-secondary-view.png)
   *Live-Hub-Oberfläche, die eine geteilte Ansicht mit dem maximierten Whiteboard und dem freigegebenen Inhalt am unteren Rand der Oberfläche zeigt.*

## Freigegebenen Inhalt mit Anmerkungen versehen

Sie können freigegebene Inhalte während einer Sitzung mit Anmerkungen versehen, um wichtige Informationen hervorzuheben, Konzepte zu erläutern oder Teilnehmer visuell zu unterstützen. Anmerkungen werden auf einen Schnappschuss des freigegebenen Bildschirms angewendet. Sie wurden für Erklärungen in Echtzeit entwickelt und bieten ein fokussiertes, ablenkungsfreies Erlebnis.

Wählen Sie bei der Freigabe Ihres Bildschirms das Symbol &quot;Anmerkung&quot; (Stift) in der oberen rechten Ecke der Bildschirmfreigabeoberfläche aus. Die Anmerkungswerkzeuge werden automatisch in der Bildschirmfreigabeoberfläche angezeigt.

### Anmerkungswerkzeuge verwenden

Wenn Sie mit der Kommentierung beginnen, wird eine Anmerkungssymbolleiste angezeigt.

![Symbolleiste für Bildschirmfreigabe-Anmerkungen](assets/screen-share-annotation-toolbar.png)
*Live-Hub-Oberfläche, die die Anmerkungssymbolleiste für die Interaktion mit dem freigegebenen Inhalt anzeigt.*

Die Anmerkungssymbolleiste bietet die folgenden Optionen:

| **Tool** | **Beschreibung** |
|----|----|
| **Auswählen** | Vorhandene Anmerkungen verwalten. Sie können Anmerkungselemente verschieben, skalieren, duplizieren oder löschen. |
| **Zeichnen** | Freihandzeichnungen erstellen. Sie können die Thickness und Farbe der Kontur anpassen. |
| **Formen** | Fügen Sie strukturierte Formen wie Rechtecke oder Kreise hinzu. Sie können die Kontur- und Füllungseigenschaften anpassen. |
| **Text** | Beschriftungen oder Erklärungen hinzufügen. Sie können Text formatieren und seine Position anpassen. |
| **Radiergummi** | Entfernen Sie Anmerkungen vom Bildschirm. Sie können einzelne Elemente löschen oder alle Anmerkungen löschen. |
| **Anmerkungen anhalten** | Beenden Sie den Anmerkungsmodus und setzen Sie die Bildschirmfreigabe fort. Alle Anmerkungen werden verworfen. |
| **Rückgängig** | Kehrt die zuletzt ausgeführte Aktion um. |
| **Wiederholen** | Wenden Sie die zuvor rückgängig gemachte Aktion erneut an. |

## Teilnehmern das Freigeben ihres Bildschirms ermöglichen

Sie können Teilnehmern die Freigabe ihres Bildschirms während einer Sitzung ermöglichen. Auf diese Weise können sie Inhalte präsentieren, Workflows demonstrieren oder Diskussionen unterstützen.

Wenn die Bildschirmfreigabe für Teilnehmer aktiviert ist:

* Die Teilnehmer können die Bildschirmfreigabe über die Sitzungssteuerelemente starten.

* Es kann immer nur eine Bildschirmfreigabe gleichzeitig aktiv sein.

* Kursleiter behalten während der Sitzung die vollständige Kontrolle über die Bildschirmfreigabe.
