# Freigeben eines Whiteboards

Verwenden Sie das Whiteboard in einer Live Hub-Sitzung, um Konzepte visuell zu erklären, Inhalte zu kommentieren und mit Teilnehmern in Echtzeit zusammenzuarbeiten. Als Kursleiter können Sie ein neues Whiteboard erstellen oder ein vorhandenes erneut öffnen, Zeichnungen, Formen und Text hinzufügen und mehrere Boards während einer Sitzung verwalten.

Sie können Boards auch umbenennen, ein Whiteboard als Bild exportieren, Teilnehmern die Zusammenarbeit an dem Board ermöglichen und externe Whiteboards wie Miro öffnen.

In diesem Artikel wird erläutert, wie Sie Whiteboards in einer Live Hub-Sitzung erstellen, verwalten, freigeben und exportieren.

## Neues Whiteboard freigeben

Starten Sie ein neues Whiteboard, wenn Sie eine neue Arbeitsfläche benötigen, um Ideen, Erklärungen oder Diagramme während einer Live-Sitzung zu präsentieren.

So teilen Sie ein neues Whiteboard:

1. Wählen Sie in der Sitzungssteuerungsleiste **Weitere Optionen**.

1. Wählen Sie **Whiteboard freigeben**.

1. Wählen Sie **Neues Whiteboard**. Ein neues Whiteboard wird geöffnet und ist für alle Teilnehmer der Sitzung sichtbar.

   ![Neues Whiteboard freigeben](assets/share-new-whiteboard.png)
   *Live-Hub-Oberfläche mit den Optionen zum Freigeben eines Whiteboards.*

## Whiteboard erneut öffnen

Sie können ein vorhandenes Whiteboard öffnen, um auf Inhalte zuzugreifen, die zuvor während der Sitzung freigegeben wurden. So können Sie Diskussionen fortsetzen oder auf früheren Erläuterungen aufbauen, ohne noch einmal von vorne beginnen zu müssen.

So öffnen Sie ein Whiteboard erneut:

1. Wählen Sie **Weitere Optionen**.

1. Wählen Sie **Whiteboard freigeben**.

1. Wählen Sie das Whiteboard aus der Liste der verfügbaren Whiteboards aus. Das ausgewählte Whiteboard wird geöffnet und ist für alle Teilnehmer sichtbar.

   ![Whiteboard erneut öffnen](assets/reopen-whiteboard.png)
   *Optionen für das Freigeben von Whiteboards zeigen die Liste der verfügbaren vorhandenen Whiteboards an.*

>[!NOTE]
>
> Sie können zuvor freigegebene Whiteboards auch über das Menü **Mehr** im Whiteboard öffnen.

## Verwenden von Whiteboard-Werkzeugen

Mit den Whiteboard-Werkzeugen kannst du während einer Live-Sitzung visuelle Erklärungen erstellen, zeichnen, Formen hinzufügen, Text einfügen und Anmerkungen hinzufügen.

![Benutzeroberfläche für Whiteboard-Tools](assets/whiteboard-tools-interface.png)
*Whiteboard-Oberfläche mit den Whiteboard-Werkzeugen.*

Verwenden Sie die folgenden Whiteboard-Werkzeuge, um Inhalte während der Sitzung zu erstellen und mit Anmerkungen zu versehen:

| **Toolreferenz** | **Beschreibung** |
|----|----|
| **Auswählen** | Wählen Sie Formen oder Text auf dem Whiteboard aus. Nachdem Sie ein Objekt ausgewählt haben, können Sie es verschieben, skalieren, drehen, duplizieren oder löschen. |
| **Schwenken** | Ziehen Sie auf der Arbeitsfläche, um in verschiedenen Bereichen des Whiteboards zu navigieren und sie anzuzeigen. |
| **Marke** | Zeichnen Sie Freihandstriche auf der Arbeitsfläche des Whiteboards. Passen Sie die Thickness mit dem Farbwähler und den Optionen für die Strichzeichnung an. |
| **Form** | Fügen Sie geometrische Formen wie Rechtecke, Kreise, Pfeile und Linien hinzu. Ziehen Sie auf der Arbeitsfläche, um eine Form zu zeichnen. Passen Sie die Füllfarbe, den Rahmen und die Thickness an. |
| **Text** | Fügen Sie dem Whiteboard Textbeschriftungen, Notizen oder Erläuterungen hinzu. Wählen Sie die Arbeitsfläche aus, um Text einzufügen. Verwenden Sie Formatierungsoptionen wie Schriftgröße, -stil und -farbe. |
| **Radiergummi** | Entfernen Sie Konturen oder Objekte aus dem Whiteboard. Der Radiergummi ermöglicht bei Zeichnungen eine teilweise Entfernung. Bei Formen oder Text wird das gesamte Objekt entfernt. |
| **Rückgängig** | Setzt die zuletzt auf dem Whiteboard ausgeführte Aktion zurück, z. B. Zeichnen, Hinzufügen von Text, Einfügen von Formen oder Löschen von Objekten. Wählen Sie **Rückgängig** mehrmals aus, um mehrere Aktionen nacheinander rückgängig zu machen. |
| **Wiederholen** | Stellt die zuletzt rückgängig gemachte Aktion auf dem Whiteboard wieder her. Wählen Sie **Wiederholen**, um Aktionen erneut anzuwenden, die zuvor mit **Rückgängig** rückgängig gemacht wurden. |

## Alle Whiteboard-Inhalte löschen

Entferne alle Zeichnungen, Formen und Texte aus dem Whiteboard. Beginne mit einer leeren Arbeitsfläche.

So löschen Sie das Whiteboard:

1. Navigieren Sie zur linken oberen Ecke des Whiteboards.

1. Wählen Sie **Weitere Optionen**.

1. Wählen Sie **Gesamten Inhalt löschen**. Der gesamte Inhalt des Whiteboards wird entfernt.

   ![Menü &quot;Whiteboard-Inhalt löschen&quot;](assets/clear-whiteboard-content-menu.png)
   *Menü &quot;Mehr&quot; mit den Optionen zum Löschen des gesamten Whiteboard-Inhalts.*

Sie können **Rückgängig** verwenden, um den gelöschten Inhalt wiederherzustellen.

## Vorhandene Whiteboards verwalten

Kursleiter können mehrere Whiteboards während einer Live-Hub-Sitzung mithilfe des Bedienfelds **Whiteboards** erstellen, organisieren und steuern. Dieses Bedienfeld hilft Ihnen, verfügbare Whiteboards zu überprüfen und Massenaktionen wie das Löschen oder Löschen von Boards durchzuführen.

So verwalten Sie vorhandene Boards:

1. Wählen Sie in der Steuerungsleiste **Weitere Optionen** aus.

1. Wählen Sie **Whiteboard freigeben**.

1. Wählen Sie **Mainboards anzeigen** aus. Das Bedienfeld **Whiteboards** wird geöffnet und zeigt alle in der Sitzung erstellten Whiteboards an.

   ![Optionen des Whiteboards-Bedienfelds](assets/whiteboards-panel-options.png)
   *Bedienfeld &quot;Whiteboards&quot; mit den Optionen zum Verwalten der vorhandenen Boards.*

### Verfügbare Aktionen im Whiteboards-Bedienfeld

Im Bereich **Whiteboards** können Kursleiter die folgenden Aktionen ausführen:

| **Aktion** | **Beschreibung** |
|----|----|
| **Freigeben** | Geben Sie das ausgewählte Whiteboard frei. |
| **Löschen** | Löschen Sie das aktuelle Whiteboard endgültig aus dem Bereich **Whiteboards**. |
| **Alle löschen** | Löschen Sie alle Whiteboards, die im Bedienfeld **Whiteboards** aufgeführt sind, endgültig. |

## Umbenennen von Whiteboards

Benennen Sie ein Whiteboard direkt über die Whiteboard-Oberfläche um, um seinen Inhalt während einer Sitzung besser zu identifizieren.

Umbenennen eines Whiteboards:

1. Wählen Sie im Bedienfeld **Whiteboards** die Option **Freigeben** aus.

1. Wählen Sie in der Whiteboard-Symbolleiste das Symbol **Bearbeiten** (Stift) neben dem Whiteboard-Namen aus.

1. Geben Sie einen neuen Namen ein und aktivieren Sie das Häkchensymbol. Das Whiteboard wird mit dem aktualisierten Namen umbenannt.

   ![Option &quot;Whiteboard umbenennen&quot;](assets/rename-whiteboard-option.png)
   *Benennen Sie die Whiteboard-Option in der Whiteboard-Oberfläche um.*

## Whiteboard-Schnappschuss als Bild exportieren

Kursleiter können Whiteboard-Inhalte als Bild exportieren, um wichtige Diskussionen, Diagramme oder Anmerkungen zu erfassen, die während einer Sitzung erstellt wurden.

So exportieren Sie einen Whiteboard-Snapshot:

1. Navigieren Sie zur linken oberen Ecke des Whiteboards.

1. Wählen Sie **Weitere Optionen**.

1. Wählen Sie **Momentaufnahme exportieren**. Der Whiteboard-Inhalt wird als **PNG**-Bild exportiert und auf Ihr lokales System heruntergeladen.

   ![Menü &quot;Whiteboard-Snapshot exportieren&quot;](assets/export-whiteboard-snapshot-menu.png)
   *Menü &quot;Mehr&quot; mit den Optionen zum Exportieren des Whiteboards als Bild.*

## Teilnehmern das Bearbeiten des Whiteboards ermöglichen

Sie können den Teilnehmern auch das Zeichnen ermöglichen und während einer Sitzung mit dem Whiteboard interagieren. Den Teilnehmern den Zugriff auf Whiteboards zu ermöglichen, erleichtert die Zusammenarbeit, das Brainstorming und die aktive Teilnahme.

So gewähren Sie Zugriff auf die Bearbeitung von Whiteboards:

1. Navigieren Sie zur linken oberen Ecke des Whiteboards.

1. Wählen Sie **Weitere Optionen**.

1. **Zeichnen zulassen** aktivieren. Die Teilnehmer können jetzt auf dem Whiteboard zeichnen, Formen hinzufügen, Text einfügen und alle verfügbaren Anmerkungswerkzeuge verwenden.

   ![Teilnehmern das Bearbeiten des Whiteboards erlauben](assets/allow-learners-edit-whiteboard.png)
   *Menü &quot;Weitere Optionen&quot; mit Steuerelementen, mit denen Teilnehmer das Whiteboard bearbeiten können.*

## Miro und andere externe Whiteboards freigeben

Kursleiter können Whiteboards von Drittanbietern, z. B. Miro, in einer Live-Hub-Sitzung freigeben.

So teilen Sie ein Miro-Board:

1. Wählen Sie in der Steuerungsleiste **Weitere Anwendungen** aus.

1. Wählen Sie **Miro** aus.

1. Melden Sie sich bei Ihrem Miro-Konto an.

   ![Miro-Whiteboard freigeben](assets/share-miro-whiteboard.png)
   Menü &quot;*Weitere Anwendungen&quot; mit den Optionen für die Freigabe des Miro-Boards.*

1. Wählen Sie auf der Miro-Projektseite das Board aus, das Sie freigeben möchten.

Teilnehmer können das freigegebene Miro Board basierend auf der Sitzungskonfiguration anzeigen, aber sie können die Miro Boards nicht öffnen oder freigeben.
