# Rolle des Administrators in der Live Hub-Sitzung

Als Administrator in Adobe Learning Manager (ALM) können Sie Schlüsselkomponenten konfigurieren und verwalten, die für die Bereitstellung von Live Hub-Schulungen erforderlich sind. Mit diesen Funktionen lassen sich Kursleiterzuweisungen, die Einrichtung von Kursen, das Branding und die Berichterstattung optimieren.

Dieser Artikel bietet einen allgemeinen Überblick über Administratoraktionen im Zusammenhang mit Live-Hub-Sitzungen. Detaillierte Konfigurationsschritte und Arbeitsabläufe finden Sie in den verknüpften Artikeln in den einzelnen Abschnitten.

## Administratorfunktionen für Live Hub

Als Administrator können Sie mit den folgenden Funktionen eine Live Hub-Schulung einrichten und durchführen. Wählen Sie einen verlinkten Artikel aus, um die einzelnen Schritte anzuzeigen.

| **Funktion** | **Was Sie tun können** | **Weitere Informationen** |
|----|----|----|
| **Livehub aktivieren** | Aktivieren Sie den Live Hub für das Adobe Learning Manager-Konto. Sie können auch KI-gestützte Assistenten aktivieren, die Autoren und Kursleiter während Live-Hub-Sitzungen unterstützen. Dazu gehören: <ul><li>Umfrage-Assistent</li><li>Q&amp;A-Assistent</li><li>Assistent zur Breakout-Überwachung</li><li>Generator zum Aufzeichnen von Themen</li><li>Assistent für die Kursleitungssuche</li></ul> | [Funktion &quot;Live-Hub aktivieren&quot;](../administrators/feature-summary/enable-live-hub.md) |
| **Kursleiterprofile verwalten** | <ul><li>Definieren von Kursleiterrollen und -verantwortlichkeiten</li><li>Weisen Sie Kenntnisse und Fachkenntnisse zu</li><li>Festlegen der Verfügbarkeit und der Unterrichtseinstellungen</li><li>Intelligentere Empfehlungen im Instructor Finder aktivieren</li></ul> | [Kursleiter hinzufügen und verwalten](./instructor-management.md) |
| **Massenkompetenzen hinzufügen** | <ul><li>Gleichzeitiges Hinzufügen mehrerer Kenntnisse</li><li>Organisieren und Aktualisieren von Qualifikationen</li><li>Kenntnisse an Kursanforderungen ausrichten</li></ul> | [Erstellen und Ändern von Kenntnissen und Stufen](../administrators/feature-summary/skills-levels.md#add-skills-in-bulk) |
| **Feiertage verwalten** | <ul><li>Feiertage hinzufügen oder durch Hochladen einer CSV-Datei mehrere Einträge gleichzeitig importieren</li><li>Legen Sie ein Datum, einen Namen und eine optionale Beschreibung für jeden Urlaub fest.</li><li>Überprüfen, suchen und filtern Sie Feiertage auf den Registerkarten &quot;Alle&quot;, &quot;Geplante&quot; und &quot;Geplante&quot;</li><li>Einen konsistenten, kontoweiten Feiertagskalender verwalten</li></ul> | [Feiertage verwalten](./manage-holidays.md) |
| **Branding- und Farbthemen konfigurieren** | <ul><li>Farbpaletten anwenden.</li><li>Über mehrere Sitzungen hinweg eine konsistente visuelle Identität wahren</li><li>Verbessern der Lernerfahrung mit markengebundenen Umgebungen</li></ul> | [Farbdesigns](../administrators/feature-summary/themes.md#color-themes) |
