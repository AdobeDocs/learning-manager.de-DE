# Feiertage verwalten

Verwenden Sie die Einstellung **Feiertage**, um organisationsweite Feiertage in Adobe Learning Manager zu definieren. Feiertage werden im Kursleiterkalender als arbeitsfreie Tage angezeigt, was sich auf die Verfügbarkeit der Kursleiter bei der Planung von Live-Hub-Sitzungen auswirkt.

Sie können Feiertage einzeln hinzufügen oder mehrere Feiertage mithilfe einer CSV-Datei importieren. Nachdem Sie Feiertage hinzugefügt haben, werden sie auf der Seite **Feiertage** angezeigt, auf der Sie sie anzeigen, durchsuchen und verwalten können.

## Auf die Feiertagseinstellungen zugreifen

So greifen Sie auf die Einstellungen für **Feiertage** zu:

1. Melden Sie sich bei Adobe Learning Manager an.

1. Wählen Sie **Einstellungen** aus **Konfiguration**.

1. Navigieren Sie zum Abschnitt **Advanced** im linken Navigationsbereich.

   ![Zugriff auf Ferieneinstellungen](assets/access-holiday-settings.png)
   *Navigieren Sie zum Abschnitt &quot;Erweitert&quot; im linken Navigationsbereich, um nach Feiertagen zu suchen.*

1. Wählen Sie **Feiertage** aus. Die Seite **Feiertage** wird angezeigt.

## Feiertage hinzufügen

Verwenden Sie die Option **Feiertag hinzufügen**, um einen einzelnen Feiertag zu erstellen oder mehrere Feiertage aus einer CSV-Datei zu importieren.

1. Wählen Sie **Hinzufügen** in der rechten oberen Ecke der Seite **Feiertage** aus. Das Popup-Fenster &quot;Feiertage hinzufügen&quot; wird angezeigt.

1. Wählen Sie eine der folgenden Optionen aus:

   1. Einzelnen Feiertag hinzufügen

   1. Feiertage gesammelt hinzufügen (CSV hochladen)

### Einzelnen Feiertag hinzufügen

So fügen Sie einen Feiertag manuell hinzu:

1. Wählen Sie **Einen Feiertag hinzufügen**.

1. Wählen Sie **Datum** und geben Sie den Feiertagsnamen ein.

1. (Optional) Geben Sie eine Beschreibung ein.

   ![Einen Feiertag hinzufügen](assets/add-single-holiday.png)
   *Wählen Sie ein Datum aus, geben Sie den Feiertagsnamen ein und fügen Sie optional eine Beschreibung hinzu.*

1. Wählen Sie **Speichern**. Der Feiertag wird der Liste hinzugefügt.

### Mehrere Feiertage hinzufügen

Fügen Sie mithilfe einer CSV-Datei mehrere Feiertage auf einmal hinzu.

1. Wählen Sie **Feiertage gleichzeitig hinzufügen (CSV hochladen)**.

1. Wählen Sie **CSV-Mustervorlage herunterladen** und fügen Sie der Datei Ihre Urlaubsdetails hinzu.

   ![CSV-Massen-Holiday-Upload](assets/bulk-holiday-csv-upload.png)
   *Laden Sie die CSV-Beispielvorlage herunter, und laden Sie dann Ihre fertige Datei hoch.*

1. Ziehen Sie die CSV-Datei in den Upload-Bereich oder wählen Sie den Upload-Bereich aus, um die Datei zu suchen und auszuwählen.

1. Wählen Sie **Speichern**. Die Feiertage werden importiert und der Liste hinzugefügt.
