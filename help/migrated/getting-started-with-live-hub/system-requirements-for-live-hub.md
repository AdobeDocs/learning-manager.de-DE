# Systemanforderungen

Verwenden Sie die folgenden Systemanforderungen, um Live Hub-Sitzungen in Adobe Learning Manager zu konfigurieren und auszuführen. Der Live Hub verwendet den gleichen Browser, das gleiche Betriebssystem und die gleichen Hardwareanforderungen wie die Umgebung für virtuelle Klassenzimmer, in der er ausgeführt wird.

Der Live Hub ist in virtuellen Klassenzimmersitzungen verfügbar und erfordert keine separate Clientinstallation.

| Kategorie | Voraussetzungen |
|---|---|
| **Desktop-Browser** | Neueste Versionen von Google Chrome, Mozilla Firefox, Microsoft Edge und Safari |
| **Mobile Browser** | Chrome Mobile, Safari Mobile und Samsung Internet |
| **Betriebssysteme** | Windows 10 oder höher, macOS 15 oder höher |
| **Bildschirmauflösungen** | 1920 × 1080, 1366 × 768, 768 × 1024 (Tablet) und 375 × 667 (mobil) |
| **Windows-Hardware** | Mindestens 8 GB RAM, 8-Core-Prozessor, Intel® Core™ i5 oder höher |
| **Mac-Hardware** | Mindestens 16 GB RAM, 4-Core-Prozessor, 3,2 GHz oder höher |
| **Netzwerk** | Stabile Breitbandverbindung mit mindestens 5 Mbit/s, empfohlen für Live-Audio- und Videowiedergabe sowie KI-gestützte Live Hub-Funktionen |

>[!NOTE]
>
>Linux-Browser, Chromebook-Geräte, Firefox Mobile, Opera (Desktop und Mobil), Internet Explorer 11 und ältere Browserversionen werden nicht unterstützt.
