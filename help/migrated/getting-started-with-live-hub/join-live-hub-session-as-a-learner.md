# Als Teilnehmer an einer Live Hub (Beta)-Sitzung teilnehmen

Teilnehmer nehmen direkt über den Kurs, für den sie registriert sind, an einer Live Hub-Sitzung teil. Sobald Sie teilnehmen, nehmen Sie über Chat, Umfragen, Tests, Whiteboards und Arbeitsräume an der Live-Schulung teil.

## An der Session teilnehmen

1. Melden Sie sich bei Adobe Learning Manager an.

1. Navigieren Sie zu **Meine Lernergebnisse**.

1. Wählen Sie den Kurs aus, für den Sie registriert sind.

   ![Angemeldeten Kurs auswählen](assets/select-enrolled-course.png)
   *Wählen Sie Gehe zu Sitzung, um den Live-Hub-Vorabbeitrittbildschirm zu öffnen.*

1. Wählen Sie **Start** > **Zu Sitzung** wechseln. Die Benutzeroberfläche für den Live-Hub-Beitritt wird geöffnet.

1. (Optional) Testen Sie das Mikrofon und wenden Sie den virtuellen Hintergrund an. Weitere Informationen finden Sie unter [Einrichten des Vorbeitrittbildschirms im Live-Hub](./setup-pre-join-screen-in-live-hub.md).

1. Wählen Sie **Verbinden**.
