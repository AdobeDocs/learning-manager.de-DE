# Freigeben Ihres Bildschirms als Teilnehmer

Als Teilnehmer können Sie bei der Bildschirmfreigabe verfolgen, was andere anwesend sind, und, wenn Ihr Kursleiter dies zulässt, Ihren eigenen Bildschirm während einer Live-Hub-Sitzung freigeben. Freigegebene Inhalte werden auf der Hauptbühne angezeigt und in Echtzeit aktualisiert, sodass Sie eine Demonstration ansehen, ein Whiteboard ansehen oder an einer laufenden Aktivität teilnehmen können.

In diesem Handbuch wird erläutert, wie Sie freigegebene Inhalte anzeigen und Ihren Bildschirm als Teilnehmer freigeben.

## Bildschirm freigeben

Sie können Ihren Bildschirm während einer Sitzung nur freigeben, wenn ein Kursleiter die Bildschirmfreigabe aktiviert hat.

Bildschirmfreigabe:

1. Wählen Sie in der Steuerungsleiste ![Bildschirm freigeben](./assets/share-screen-icon.svg) aus. Es wird ein Popupfenster angezeigt.

1. Wählen Sie eine der folgenden Optionen aus:

   1. **Registerkarte &quot;Chrome&quot;**: Geben Sie eine Browser-Registerkarte frei.

   1. **Fenster**: Freigeben einer bestimmten Anwendung.

   1. **Gesamter Bildschirm**: Den Vollbildschirm freigeben.

1. (Optional) Aktivieren Sie **Audio der Registerkarte &quot;**&quot; ebenfalls freigeben, um Audio von der freigegebenen Registerkarte einzuschließen.

1. Wählen Sie den Inhalt aus, den Sie freigeben möchten.

1. Wählen Sie **Freigeben** aus. Der ausgewählte Inhalt wird allen Teilnehmern angezeigt.

   ![Ansicht für Bildschirmfreigabe für Teilnehmer](assets/learner-screen-share-view.png)
   *Live-Hub-Oberfläche, auf der der vom Teilnehmer freigegebene Bildschirm angezeigt wird.*

## Anmerkungswerkzeuge verwenden

Während Sie Ihren Bildschirm freigeben, können Sie Anmerkungen dazu einfügen, um Informationen hervorzuheben oder anderen in der Sitzung Inhalte zu erläutern. Um eine Anmerkung zu erstellen, wählen Sie das Anmerkungssymbol (Stiftsymbol) in der oberen rechten Ecke des freigegebenen Bildschirms aus. Weitere Informationen finden Sie unter [Anmerkungstools verwenden](../getting-started-with-live-hub/share-your-screen-as-an-instructor.md#use-annotation-tools).
