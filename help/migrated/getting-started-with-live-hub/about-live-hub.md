# Live Hub

Der Live Hub bringt die virtuelle Lernumgebung nativ in Adobe Learning Manager ein, sodass es keinen Wechsel zwischen Ihrem Learning-Management-System (LMS) und einem Konferenzwerkzeug gibt. Jede Sitzung wird automatisch nachverfolgt und ein umfangreiches Session-Dashboard zeigt den Kursleitern, wie die Teilnehmer interagieren, und das weit über die Anwesenheit hinaus.

AI Agents in Live Hub wurden speziell für Live-Schulungen entwickelt und arbeiten durchgehend zusammen mit dem Kursleiter. Sie schlagen Umfragen vor, erkennen Fragen von Teilnehmern und bieten Antworten, überwachen die Arbeitsräume live und generieren Sitzungszusammenfassungen, sodass sich die Lehrkräfte auf die Bereitstellung von Schulungen konzentrieren können. Und für die Teilnehmer werden Aufzeichnungen automatisch in navigierbare Themen segmentiert, sodass die Wiedergabe so strukturiert und nützlich ist wie die Live-Teilnahme.

Live Hub unterstützt Kursleiter bei der Bereitstellung ansprechender virtueller Schulungen und hilft Unternehmen bei der Durchführung interaktiver Live-Schulungen in großem Umfang. Live Hub (Beta) wird demnächst in der kommenden August-Version von Adobe Learning Manager veröffentlicht.
