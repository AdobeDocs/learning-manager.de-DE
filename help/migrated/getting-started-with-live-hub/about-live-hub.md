# Live Hub

Der Live Hub bringt die virtuelle Lernumgebung nativ in Adobe Learning Manager ein, sodass es keinen Wechsel zwischen Ihrem Learning-Management-System (LMS) und einem Konferenzwerkzeug gibt. Jede Sitzung wird automatisch nachverfolgt und ein umfangreiches Session-Dashboard zeigt den Kursleitern, wie die Teilnehmer interagieren, und das weit über die Anwesenheit hinaus.

AI Agents in Live Hub wurden speziell für Live-Schulungen entwickelt und arbeiten durchgehend zusammen mit dem Kursleiter. Sie schlagen Umfragen vor, erkennen Teilnehmerfragen und schlagen Antworten vor, überwachen Arbeitsräume live und generieren Sitzungszusammenfassungen, sodass sich die Kursleiter auf die Durchführung der Schulungssitzung konzentrieren können. Für Teilnehmer werden Aufzeichnungen automatisch in navigierbare Themen segmentiert, sodass die Wiedergabe so strukturiert und nützlich ist wie die Live-Teilnahme.

Live Hub unterstützt Kursleiter bei der Bereitstellung ansprechender virtueller Schulungen und hilft Unternehmen bei der skalierten Durchführung interaktiver Live-Schulungen.

>[!NOTE]
>
>Der Live Hub wird mit der bevorstehenden Version **August** von Adobe Learning Manager verfügbar sein. Die Dokumentation für Live Hub ist verfügbar, sobald die Funktion veröffentlicht wurde.
