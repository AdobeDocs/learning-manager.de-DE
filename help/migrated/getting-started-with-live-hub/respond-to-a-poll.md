# Auf eine Umfrage antworten

Als Teilnehmer helfen Ihnen Umfragen dabei, aktiv an einer Live Hub-Sitzung teilzunehmen. Wenn ein Kursleiter eine Umfrage startet, wird sie im Bereich **Umfragen und Tests** angezeigt, in dem Sie Ihre Antwort senden können, indem Sie eine oder mehrere Optionen auswählen oder je nach Umfragetyp eine kurze Textantwort eingeben. Sie können Ihre Antwort aktualisieren, während die Umfrage geöffnet bleibt. Wenn der Kursleiter die Ergebnisse mitteilt, können Sie die Umfrageergebnisse in Echtzeit anzeigen. In diesem Artikel wird erläutert, wie Sie während einer Sitzung auf Umfragen antworten und gemeinsame Ergebnisse anzeigen.

## Antwort senden

Wenn ein Kursleiter eine Umfrage während einer Sitzung startet, wird sie auf Ihrem Bildschirm angezeigt. Um auf eine Umfrage zu antworten, führen Sie basierend auf dem Umfragetyp einen der folgenden Schritte aus:

1. **Multiple-Choice- oder Multiple-Response-Umfrage**: Wählen Sie die entsprechende(n) Antwortoption(en) aus.

1. **Umfrage mit kurzen Antworten**: Geben Sie Ihre Antwort in das Textfeld ein.

Nach dem Senden wird die Meldung **Ihre Antwort wurde aufgezeichnet** angezeigt.

## Antwort aktualisieren

Sie können Ihre Antwort ändern, solange die Abstimmung noch live ist. Die Abstimmung bleibt auf Ihrem Bildschirm.

Um Ihre Antwort zu aktualisieren, wählen Sie eine andere Antwortoption aus oder bearbeiten Sie Ihre Textantwort. Die aktualisierte Auswahl wird automatisch gespeichert.
