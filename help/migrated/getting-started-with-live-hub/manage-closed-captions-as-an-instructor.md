# Verwalten von Untertiteln als Kursleiter

In Untertiteln werden gesprochene Inhalte als Text auf dem Bildschirm angezeigt, sodass eine Live Hub-Sitzung z. B. während der Präsentation, der Beantwortung von Teilnehmerfragen oder der Arbeit in einer lauten Umgebung einfacher nachzuvollziehen ist. Als Kursleiter können Sie Ihre eigenen Untertitel im Raum &quot;**Weitere Aktionen**&quot; verwalten.

In diesem Artikel wird erläutert, wie Sie Untertitel während einer Live Hub-Sitzung anzeigen, anpassen und ausblenden.

## Anzeigen von Bilduntertiteln

Zeigt während einer Live Hub-Sitzung Untertitel an, um die Transkription gesprochener Inhalte in Echtzeit anzuzeigen.

So aktivieren Sie Bilduntertitel:

1. Wählen Sie **Weitere Optionen (⋯)** in der Steuerungsleiste aus.

1. Wählen Sie **Untertitel** aus.

1. Aktivieren Sie **Untertitel anzeigen**. Untertitel werden am unteren Rand der Benutzeroberfläche angezeigt.

   ![Kursleiter für Untertitel aktivieren](assets/enable-closed-captions-instructor.png) *Aktivieren Sie Untertitel anzeigen, um die Untertitel in der Sitzung anzuzeigen.*

## Ändern des Erscheinungsbilds von Untertiteln

Sie können das Erscheinungsbild von Untertiteln während einer Sitzung anpassen, um die Lesbarkeit basierend auf Ihren Anzeigeanforderungen zu verbessern.

So ändern Sie die Darstellung von Untertiteln:

1. Wählen Sie **Weitere Optionen (⋯)**.

1. Wählen Sie **Untertitel** aus.

1. Wählen Sie eine der folgenden Optionen aus:

   1. **Schriftgröße**: Wählen Sie eine Größe für den Text der Untertitel aus. Die verfügbaren Optionen sind **Klein**, **Mittel** und **Groß**.

   1. **Beschriftungsformat**: Wählen Sie eine Farbkombination aus. Die verfügbaren Kombinationen sind **Schwarz auf Weiß**, **Gelb auf Schwarz**, **Weiß auf Schwarz**, **Dunkel auf Gelb** und **Gelb auf Blau**.

   ![Aussehenlehrer für Bilduntertitel](assets/closed-captions-appearance-instructor.png)
   *Wählen Sie Schriftgrad aus, um die Größe des in den Untertiteln angezeigten Textes zu ändern.*
