# Virtual Coach-Berichte

Als Administrator können Sie zwei Berichte im Zusammenhang mit Virtual Coach anzeigen. Es handelt sich um **Zusammenfassung der Teilnehmernutzung** und **Sitzungsdetails**.

![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report1.png)

## Übersicht über die Teilnehmernutzung

Die Übersicht zur Teilnehmernutzung enthält monatliche Nutzungsdetails aller Teilnehmer, die im Konto registriert sind. Diese Nutzungsdetails enthalten Einblicke in Nutzung und Lernmuster.

### Übersicht über die Teilnehmernutzung generieren

So generieren Sie eine Übersicht zur Teilnehmernutzung:

1. Melden Sie sich als Administrator an.
2. Navigieren Sie zu **Verwalten** > **Berichte** > **AI-Berichte**.
3. Wählen Sie im Abschnitt **Virtueller Coach** die Option **Übersicht zur Teilnehmernutzung**. Das Popup **Virtuelle Trainer-Teilnehmernutzungsdaten** wird angezeigt.
4. Wählen Sie das **Startdatum** und das **Enddatum**.
5. **Fortfahren** auswählen. Der Bericht wird als CSV-Datei generiert. Sie finden die heruntergeladene CSV-Datei im Ordner &quot;**Downloads**&quot; Ihres Datei-Explorers.

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report2.png)

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report-learn-usage-6.png)

## Sitzungsdetails

Der Bericht **Sitzungsdetails** enthält Sitzungsdetails aller Teilnehmer, die in den letzten 90 Tagen im Konto registriert sind. Diese Nutzungsdetails enthalten Einblicke in Nutzung und Lernmuster.

### Sitzungsdetails generieren

So generieren Sie einen Sitzungsdetailbericht:

1. Melden Sie sich als Administrator an.
1. Navigieren Sie zu **Verwalten** > **Berichte** > **AI-Berichte**.
1. Wählen Sie im Abschnitt **Virtueller Coach** die Option **Sitzungsdetails** aus. Das Popup **Berichtsanforderung wird generiert** wird angezeigt.
1. Klicken Sie auf **OK**. Der Bericht wird als CSV-Datei generiert. Sie finden die heruntergeladene CSV-Datei im Ordner &quot;**Downloads**&quot; Ihres Datei-Explorers.

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report3.png)

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report-session-4.png)

>[!NOTE]
>
>Adobe Learning Manager speichert keine Aufzeichnung der Virtual Coach-Sitzung eines Teilnehmers. Ein Teilnehmer kann mehrere Sitzungen absolvieren. Der Teilnehmer darf jedoch nicht zu einer früheren virtuellen Coach-Sitzung zurückkehren.
