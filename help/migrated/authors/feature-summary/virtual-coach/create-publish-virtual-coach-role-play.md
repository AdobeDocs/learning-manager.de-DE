# Erstellen und Veröffentlichen eines virtuellen Coach-Rollenspiels

Erstellen Sie in Adobe Learning Manager Virtual Coach ein KI-Rollenspielszenario, damit die Teilnehmer im Rahmen eines Kurses oder einer Arbeitshilfe echte Gespräche führen können. In diesem Artikel wird der gesamte Prozess zur Erstellung eines virtuellen Coach-Rollenspiels beschrieben - von der Auswahl einer Vorlage bis hin zur Veröffentlichung in der Inhaltsbibliothek.

Bevor Sie beginnen, bestätigen Sie, dass Adobe Learning Manager Virtual Coach für Ihr Konto aktiviert ist und dass Sie als Autor angemeldet sind. Virtual Coach baut jedes Rollenspiel aus den von Ihnen bereitgestellten Materialien auf und fordert Details dazu auf - es zieht nicht automatisch die vorhandenen Kursinhalte Ihres Unternehmens auf. Wenn Sie dies noch nicht getan haben, [sammeln Sie Materialien für ein Virtual Coach-Rollenspiel](/help/migrated/authors/feature-summary/virtual-coach/gather-materials-for-virtual-coach-role-play.md), bevor Sie beginnen.

So erstellen Sie ein AI-Rollenspielszenario im virtuellen Coach:
1. Wählen Sie im linken Navigationsbereich **Virtueller Coach** und dann **Jetzt erstellen**.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach1.png)

2. Wählen Sie im Abschnitt **Empfohlen** eine Vorlage für **Einzelpersonen** oder **mehrere Personen** aus. In diesem Beispiel nehmen wir an, dass dieses Rollenspiel auf einer einzigen Person basiert. Weitere Informationen zu Schritten mit mehreren Personen finden Sie unter [Rollenspiel für mehrere Personen](#configure-a-multi-persona-role-play).

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach2.png)

   Das Fenster **Rollenspiel erstellen** wird geöffnet.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach14.png)

3. Laden Sie optional das Quell-Material hoch und wählen Sie dann **Mit AI gemeinsam erstellen**.
4. Konfigurieren Sie die Persona, das Öffnen von Konversationen und die Evaluierungsthemen.
5. Wählen Sie im Abschnitt **Themen, die abgedeckt werden sollen** die Option **Bearbeiten** aus. Legen Sie Bewertungsgewichte und alle **Make- oder Break**-Themen fest.
6. Jeder Abschnitt kann auf diese Weise bearbeitet werden.
7. Wenn Sie mit dem Inhalt zufrieden sind, wählen Sie **Inhalt genehmigen und fortfahren**.

   ![](/help/migrated/authors/feature-summary/assets/virtual-coach16.png)

8. Zeigen Sie eine Vorschau des Rollenspiels und anschließend **Publish** an.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach17.png)

## Öffnen Sie den virtuellen Coach und starten Sie ein Rollenspiel

Es gibt zwei Möglichkeiten, ein virtuelles Coach-Rollenspiel zu erstellen: mit einer Vorlage beginnen oder eine Vorlage mit dem KI-Co-create-Assistenten neu erstellen. Dieser Abschnitt behandelt Gebäude von Grund auf.

1. Melden Sie sich bei Adobe Learning Manager als Autor an.
2. Wählen Sie im linken Navigationsbereich **Virtueller Coach** aus.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach1.png)
   *Wählen Sie im linken Navigationsbereich unter &quot;Erstellen&quot; die Option &quot;Virtueller Coach&quot; aus, um mit dem Erstellen eines Rollenspiels zu beginnen.*

3. Wählen Sie auf der Seite **Virtueller Coach** die Option **Jetzt erstellen** aus.
4. Wählen Sie eine Vorlage im Abschnitt **Empfohlen** oder im Abschnitt **Verfügbare Vorlagen** aus. In den Templates findest du zwei Optionen, mit denen du ein neues Projekt erstellen kannst:
   - **Rollenspiel für Einzelpersonen (AI-Assistent)**: der Teilnehmer interagiert mit einer AI-Person. Verwenden Sie diese Option für ein Kundengespräch, eine Führungsdiskussion, einen Discovery-Anruf oder ein Coaching-Gespräch.
   - **Rollenspiel für mehrere Personen (Beta)**: der Teilnehmer mit bis zu vier KI-Personen in derselben Konversation interagiert. Verwenden Sie diese Option für eine Überprüfung durch den Vorstand, für ein Beschaffungs-, Finanz- und Rechtskomitee oder für Kundenverhandlungen, an denen mehrere Stakeholder beteiligt sind, z. B. ein Szenario, bei dem ein Mitarbeiter einem CFO, einem Beschaffungsmanager, einer IT-Director und einem Champion für Endbenutzer in einer Sitzung ein neues Angebot unterbreiten muss.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach2.png)
   *Wählen Sie im Abschnitt &quot;Empfohlen&quot; die Option &quot;Rollenspiel für Einzelpersonen&quot; oder &quot;Rollenspiel für mehrere Personen&quot;, um ein Szenario von Grund auf neu zu erstellen, oder wählen Sie unten eine vordefinierte Vorlage aus.*

   Wählen Sie für dieses Beispiel im Abschnitt **Empfohlen** die Option **Rollenspiel für Einzelpersonen (AI-Assistent)**. Informationen zum Starten eines vorbereiteten Szenarios finden Sie unter [Erstellen eines Rollenspiels mithilfe einer Vorlage für virtuelle Coaches](/help/migrated/authors/feature-summary/virtual-coach/create-role-play-using-virtual-coach-template.md).
5. Wählen Sie optional **Dateien hochladen**, um unterstützende Dokumente wie ein Produktdatenblatt, ein Playbook oder eine Aufrufaufzeichnung hinzuzufügen. Der KI-Co-Create-Assistent verwendet diese Funktionen, um ein präziseres Szenario zu erstellen. Überspringen Sie diesen Schritt, wenn Sie keine relevanten Dateien haben.
6. Wählen Sie **Mit KI gemeinsam erstellen**. Wenn die Bestätigungsmeldung angezeigt wird, wählen Sie **Generieren**.
7. Geben Sie eine Beschreibung für Ihr Rollenspiel ein. Verwenden Sie eine Beschreibung, die das Szenario umreißt, z. B. `Handling price objections in enterprise sales` oder `Pitching our new product to a buying committee`.
8. Setzen Sie die Unterhaltung mit dem AI-Assistenten fort und fügen Sie weiteren Kontext zum Szenario hinzu. Der Assistent erläutert, dass ein Rollenspiel drei Hauptkomponenten hat: **Übersicht** (Titel und Konversationskontext), **AI persona** (Name, Organisation, Rolle, Hintergrund, Bedenken usw.) und **Evaluierungsthemen** (die Kriterien, die zum Punktwert für Teilnehmer verwendet werden). Er fragt, ob Sie diese Schritt für Schritt erstellen oder alle gleichzeitig generieren möchten.
9. Fügen Sie weitere Informationen hinzu, oder wählen Sie **Inhalte genehmigen und**, wenn Sie zufrieden sind.

## Rollenspieleinstellungen konfigurieren

Nachdem Sie ein virtuelles Coach-Rollenspiel mithilfe des KI-Co-Create-Assistenten erstellt haben, wird der Bildschirm **Rollenspiel bearbeiten** geöffnet. Ihr Fortschritt wird automatisch gespeichert, wie die Anzeige **Gespeichert** in der oberen rechten Ecke zeigt. Sie können diesen Bildschirm jederzeit verlassen und zurückkehren, ohne Ihre Arbeit zu verlieren.

Auf diesem Bildschirm stehen Ihnen drei Optionen zur Verfügung:

- **Preview** führt eine Live-Testsitzung aus, damit Sie das Rollenspiel als Teilnehmer erleben können, bevor andere es tun. So können Sie sicherstellen, dass die Person natürlich klingt und die Themen richtig fließen.
- **Speichern** speichert den aktuellen Status ohne Veröffentlichung. Das Rollenspiel wird dem Abschnitt **Verfügbare Vorlagen** Ihrer virtuellen Coach-Bibliothek hinzugefügt, in dem Sie es später erneut bearbeiten können.
- **Publish** fügt das Rollenspiel der **Inhaltsbibliothek** hinzu, sodass es einem Kurs oder einer Arbeitshilfe zugewiesen werden kann.

Um Änderungen am generierten Inhalt vorzunehmen, ohne die Felder manuell zu bearbeiten, wählen Sie rechts **Mit AI bearbeiten** aus. Dadurch wird die AI-Chat-Oberfläche geöffnet und Sie können die gewünschten Änderungen in einfacher Sprache beschreiben, z. B. `make the persona more formal` oder `add a topic about pricing objections`.

>[!NOTE]
>
>Dies unterscheidet sich von der abschnittsweisen Bearbeitung. Mit der Option zur abschnittsweisen Bearbeitung haben Sie Zugriff auf alle Abschnitte gleichzeitig. Auf der anderen Seite bietet Ihnen die KI-Chat-Oberfläche die Möglichkeit, frei zu beschreiben, was Sie ändern möchten.

Wählen Sie **Bearbeiten** neben **Rollenspieltitel** aus, um den Titel zu ändern.

## Personalisieren Sie Ihre Virtual Coach-Simulation

Definiert den Kontext der Unterhaltung, den Hintergrund der Person und die Anliegen der Person, um euer Rollenspielszenario realistisch und herausfordernd zu gestalten. Je mehr Details du in den einzelnen Feldern anzeigst, desto genauer und konsistenter verhält sich die KI-Person während der Simulation.

Wenn Sie **Co-Create mit KI verwenden** oder **Rollenspiel automatisch generieren**, werden diese Felder basierend auf Ihren Eingaben vorausgefüllt. Überprüfen und optimieren Sie sie vor der Veröffentlichung.

### Gesprächskontext

Das Feld **Konversationskontext** legt die Bühne für den Teilnehmer fest. Sie teilt der KI-Person den Hintergrund und Zweck des Rollenspiels mit, sodass die Person versteht, warum die Konversation stattfindet und was der Hauptfokus sein sollte.

>[!NOTE]
>
>Dieses Feld wurde für die KI-Person geschrieben, nicht für den Teilnehmer. Fügen Sie hier keine Anweisungen oder Richtlinien für den Teilnehmer hinzu. Verwenden Sie das Feld **AI Trainer Opener**, das weiter unten in diesem Artikel beschrieben wird, für den Kontext, der auf die Teilnehmer zugeschnitten ist.

Beim Schreiben des Konversationskontexts:

- **Die Situation erläutern.** Beschreiben Sie, um welche Art von Konversation es sich handelt, z. B. einen Verkaufsberatungsaufruf, einen Kaltanruf oder einen Kurzanruf, und wer den Anruf veranlasst hat.
- **Beschreiben Sie die Position der AI-Person.** Erklären Sie, wer die Person in Bezug auf den Teilnehmer ist. Beispiel: Ein Kunde, der ein Produkt bewertet, ein CFO, der ein Budgetangebot prüft, oder ein Mitarbeiter, der Feedback erhält.
- **Verwenden Sie &quot;den Teilnehmer&quot; konsistent.** Wenn Sie sich auf die Person beziehen, mit der die Person spricht, schreiben Sie immer &quot;den Teilnehmer&quot;. Vermeiden Sie Beschriftungen wie &quot;der Agent&quot;, &quot;der Verkäufer&quot; oder &quot;der Vertreter&quot;, die zu inkonsistentem persönlichen Verhalten führen können.
- **Präzise halten.** Geben Sie nur Informationen an, die für die Einrichtung der Unterhaltung relevant sind. Speichern Sie persönliche Details für **Persona Background Information**.

**Beispiel:** &quot;Dies ist ein Aufruf zur Ermittlung des Verkaufs. Die Lernende hat sich an einen Einführungstermin mit Karen Mitchell, der Medical Affairs Director, in einem mittelgroßen Krankenhausnetzwerk gewandt. Karen stimmte einem 15-minütigen Anruf zu, um mehr über die Lernplattform zu erfahren. Sie hat nur begrenzte Zeit und kann beurteilen, ob die Plattform die Qualitätsstandards für klinische Inhalte erfüllt, bevor sie ihr Team einschaltet.&quot;

### Persona background information

Das Feld **Persona Background Information** verleiht der AI-Person eine Persönlichkeit. Je mehr Details du eingibst, desto genauer und konsistenter sind die Antworten der Person während der gesamten Simulation.

Umfasst:

- **Allgemeine Details**: den Namen, das Alter, die Rolle und die aktuelle Situation der Person in Bezug auf das Thema und das Ziel des Rollenspiels.
- **Motivationen und Ziele**: worum es der Person geht, was sie erreichen will oder was sie ändern will, und ihre Schmerzpunkte.
- **Überzeugungen und Einstellungen**: wie sich die Person über das Gesprächsthema und die Organisation des Teilnehmers fühlt.
- **Verhalten und Gewohnheiten**: Tendenzen, die die Perspektive der Person prägen, wie vorsichtige Entscheidungsfindung oder der Eifer, neue Instrumente einzuführen.
- **Entscheidungskriterien**: was die Person davon überzeugt, voranzukommen, und welche Einschränkungen sie einhält, wie Zeit, Budget oder Genehmigungsprozesse.

>[!TIP]
>
>Spezifische Details helfen der Person, auf natürliche und glaubwürdige Weise zu reagieren. Generische Hintergründe erzeugen ein generisches Verhalten.

### Persönliche Anliegen

**Persona Concerns** definieren die spezifischen Probleme, Sorgen oder Fragen, die die Person während der Unterhaltung aufwirft. Diese Bedenken treiben den Fluss des Rollenspiels voran und stellen sicher, dass der Teilnehmer auf realistische Herausforderungen reagieren muss.

- **Geben Sie drei bis fünf Bedenken an.** Formuliert jeden Aspekt als Anliegen oder Frage, und formuliert ihn spezifisch und umsetzbar. Vermeidung vager Bedenken wie &quot;Kostensorgen&quot;; schreiben &quot;besorgt, dass die jährlichen Lizenzkosten das Ermessensbudget der Abteilung ohne Genehmigung des CFO überschreiten.&quot;
- **Konzentration auf jedes Problem auf ein einzelnes Thema.** Ein Problem pro Thema sorgt dafür, dass die Konversation einfach gehalten wird und jede Herausforderung klar bewertet wird.
- **Geben Sie an, wann die Sorge aufkommt.** Geben Sie den Punkt in der Konversation an, an dem die Person sie anhebt.
- **Definieren Sie, was gut genug ist, um fortzufahren.** Beschreiben Sie, was die Konversation voranbringen würde. Beispielsweise versichert der Teilnehmer die Person, stellt eine Referenz bereit oder bietet Dokumentation an.

Schreiben Sie jedes Problem mithilfe dieser Struktur: **Bedenken →, wenn →, was gut genug ist, um vorwärts zu kommen.**

**Beispiel:** &quot;Bedenken — Genauigkeit klinischer Inhalte: wird angezeigt, wenn der Teilnehmer den Prozess zum Erstellen von Inhalten beschreibt. Gut genug: Der Teilnehmer gibt explizit an, dass die Inhalte von medizinischen Fachkräften erstellt, begutachtet und mit Primärliteratur oder anerkannten klinischen Richtlinien verknüpft werden.&quot;

Nachdem Sie die relevanten Informationen eingegeben haben, wählen Sie **Speichern**.

>[!TIP]
>
>Testen Sie das Timing von Bedenken mit **Vorschau**. Eine Sorge, die zu früh oder zu spät erscheint, stört den Gesprächsfluss.

>[!NOTE]
>
>Änderungen an den persönlichen Einstellungen werden sofort für alle unveröffentlichten Rollenspiele wirksam. Wenn Sie ein Rollenspiel bearbeiten, das bereits veröffentlicht ist und Teilnehmern zugewiesen wurde, veröffentlichen Sie es erneut, um die aktualisierte Person auf zukünftige Sitzungen anzuwenden.

## Konfigurieren einer Präsentation für Ihre Simulation

Verwenden Sie den Abschnitt **Präsentationseinstellungen**, um Ihrer Rollenspielsimulation ein Folien-Deck hinzuzufügen. Wenn eine Präsentation angehängt ist, können die Teilnehmer sie während der Sitzung als Referenz oder Sprechhilfe anzeigen. Beispiel: eine Produktübersicht, die während einer Verkaufsgesprächssimulation verwendet wird.

1. Wählen Sie unter **Präsentationsdetails** die Option **PDF oder PPTX** hochladen.
2. Wähle die gewünschte Datei aus. Es werden sowohl PDF- als auch PPTX-Formate mit einer maximalen Dateigröße von 100 MB unterstützt.
3. Nach dem Hochladen wird der Dateiname unter der Schaltfläche angezeigt und bestätigt den Anhang.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach3.png)
   *Fügen Sie eine Präsentation hinzu, damit die Teilnehmer während der Simulation auf sie als Sprechhilfe verweisen können.*

4. Wählen Sie **Fertig**, um die Einstellung zu speichern und zur Rollenspielkonfiguration zurückzukehren.

Sobald Sie eine Präsentation hochladen, wird die Option **Teilnehmern das Hochladen einer eigenen Präsentation erlauben** automatisch aktiviert. Sie können die angehängte Datei auch über die Schaltflächen auf der rechten Seite herunterladen oder löschen.

Wählen Sie **Teilnehmern das Hochladen einer eigenen Präsentation erlauben**, wenn jeder Teilnehmer mit einer eigenen Version einer Präsentation anstatt mit einer freigegebenen üben soll. Dies ist nützlich, wenn die Teilnehmer anhand einer von ihnen persönlich vorbereiteten Präsentation bewertet werden, z. B. bei einem Geschäftsbericht oder einem individuellen Verkaufsgespräch. Dieser Umschalter ist standardmäßig deaktiviert. Wenn diese Option aktiviert ist, wird den Teilnehmern zu Beginn ihrer Sitzung eine Upload-Aufforderung angezeigt.

>[!NOTE]
>
>Stellen Sie sicher, dass alle von Ihnen hochgeladenen Präsentationen zugänglich sind. Verwende einen ausreichenden Farbkontrast, füge Alternativtext zu Bildern hinzu, und vermeide Inhalte, die ausschließlich auf Farbe basieren, um eine bestimmte Bedeutung zu vermitteln.

## KI-Persona einrichten.

Der Abschnitt **Einrichtung von KI-Mitarbeitern** steuert, mit wem der Teilnehmer während der Simulation spricht, zusammen mit seinem Erscheinungsbild, seiner Stimme, seiner Rolle und seiner Verhaltenspersönlichkeit. Dieser Abschnitt ist einer der wichtigsten Aspekte beim Erstellen eines AI-Rollenspielszenarios, da eine gut konfigurierte AI-Avatar-Person das Rollenspiel realistisch wirken lässt und sicherstellt, dass sich KI konsistent mit dem Szenario verhält, das Sie entwickelt haben.

### Auswählen einer Person

Es sind zwei Registerkarten verfügbar: **Systempersonas** und **Benutzerdefinierte Personas**.

**Systempersonas** sind vordefinierte Zeichen, die von Adobe bereitgestellt werden. Jeder verfügt über einen Namen, ein Foto und einen oder zwei unterstützte Interaktionsmodi: **Stimme und Video** (die Person erscheint als animierter Avatar mit einer gesprochenen Stimme) oder **Stimme** (nur gesprochene Stimme, kein Video-Avatar). Wählen Sie eine Systempersona aus, indem Sie deren Kachel auswählen.

**Benutzerdefinierte Personas** sind Personas, die Sie zuvor erstellt haben. Wählen Sie diese Registerkarte, um eine AI-Avatar-Person aus einem früheren Rollenspiel wiederzuverwenden, anstatt eine von Grund auf neu zu erstellen.

![](/help/migrated/authors/feature-summary/assets/virtual_coach4.png)
*Verwenden Sie eine benutzerdefinierte Person aus einem früheren Rollenspiel erneut, anstatt eine neue Person von Grund auf neu zu erstellen.*

Sie können eine Person auf zwei Arten wiederverwenden: bearbeiten Sie die Details direkt, um sie in eine andere Person umzuwandeln, oder wählen Sie **Duplizieren** aus, um eine Kopie zu erstellen und die Details der Kopie zu ändern. Um beide Optionen anzuzeigen, wählen Sie das Symbol mit den vertikalen Auslassungspunkten (**⋮**), das in der oberen rechten Ecke des Bildes einer Person angezeigt wird, wenn Sie den Mauszeiger darüber bewegen oder es auswählen.

### Persönliche Details und Persönlichkeit konfigurieren

Füllen Sie nach der Auswahl einer Person die Felder &quot;**AI Persona Details**&quot; aus:

1. Geben Sie die **Rolle** der Person ein - ihre Stellenbezeichnung, wie sie in der Simulation angezeigt werden soll, z. B. Medical Affairs Director.
2. Geben Sie die **Organisation** der Person ein - das Unternehmen oder die Institution, für das bzw. die sie arbeitet. Zum Beispiel Northgate Health.
3. Wählen Sie eine **Persönlichkeit** aus, die der Challenge-Ebene und dem Szenariokontext entspricht:

   | Persönlichkeit | Verhalten |
   |---|---|
   | skeptisch | Stellt alles in Frage und verlangt Nachweise |
   | Gleichgültig | Ungebunden und schwer zu erregen |
   | enthusiastisch | Von der Lösung begeistert und einsatzbereit |
   | Beziehungsorientiert | Werte vor allem Vertrauen und persönliche Verbindung |
   | Neutral | Bleibt ausgeglichen und bewertet Optionen ohne Voreingenommenheit. |
   | selbstüberzeugt | Stark, schnell und neigt dazu, andere herauszufordern |

4. Optional können Sie **Teilnehmern die Auswahl dieser Option vor dem Rollenspiel erlauben**, damit Teilnehmer die Persönlichkeit der Person vor dem Starten der Sitzung auswählen können. Dies ist nützlich für Szenarien im Übungsmodus, in denen Teilnehmer den Schwierigkeitsgrad steuern möchten.
5. Wählen Sie **Fertig**, um die persönliche Konfiguration zu speichern.

>[!TIP]
>
>Passen Sie die Persönlichkeit an die Herausforderung des Szenarios an. Ein Cold-Call-Szenario profitiert von einer **Skeptischen** oder **Ununterschiedlichen** Person, um einen schwierigen Interessenten zu simulieren. Ein Feedback-Szenario für Führungskräfte eignet sich gut für **Assertive** oder **Beziehungsorientiert**, um realistische Manager-Mitarbeiter-Dynamiken widerzuspiegeln.

### Erstellen einer benutzerdefinierten Persona

Wenn die Systempersonas nicht in Ihr Szenario passen, erstellen Sie ein neues auf der Registerkarte **Benutzerdefinierte Personas**.

1. Wählen Sie **Benutzerdefinierte Personas** aus, und wählen Sie dann **Neue Persona erstellen** aus.
2. Laden Sie ein Foto für die Person hoch. Das Bild muss mindestens 640 x 360 Pixel groß und darf nicht größer als 1 MB sein.
3. Geben Sie den **Vornamen** der Person ein.
4. Wählen Sie im Dropdown-Menü eine **Stimme** aus, um die Sprechstimme der KI festzulegen.
5. Passen Sie den Schieberegler für die **Sprachrate** an, um die Sprechgeschwindigkeit von -100 (langsamer) bis +100 (schnellster) zu steuern. Der Standardwert ist 0 (neutrales Leerzeichen). Wählen Sie &quot;**Stimme testen**&quot; aus, um vor dem Speichern eine Vorschau des Sounds der Stimme anzuzeigen.
6. Wählen Sie **Persona erstellen** aus. Die neue Person wird auf der Registerkarte **Benutzerdefinierte Personas** gespeichert und ist für die Verwendung in zukünftigen Rollenspielen verfügbar.

>[!NOTE]
>
>Benutzerdefinierte Personas unterstützen Sprachinteraktionen. Vergewissern Sie sich vor der Veröffentlichung, dass die Sprachrate für das Szenario natürlich klingt. Eine sehr schnelle oder sehr langsame Rate kann dazu führen, dass sich die Simulation unnatürlich anfühlt und sich auf die Punktzahl des Teilnehmers auswirkt.

Durch Aktivieren von **Video Avatar** wird dem Rollenspiel ein fotorealistischer AI-Video-Avatar hinzugefügt. Video-Avatare sind für Personen verfügbar, die den Modus **Sprache und Video** unterstützen. Jeder Teilnehmer erhält 300 Minuten Video-Rollenspiel pro Monat. Sobald diese Grenze erreicht ist, ändert sich die Erfahrung in einen statischen Avatar.

### Konfigurieren eines Rollenspiels mit mehreren Personen

Verwenden Sie ein persönliches Rollenspiel, wenn der Teilnehmer in einer Unterhaltung mit mehr als einem Stakeholder in derselben Sitzung navigieren muss. Beispiel: Einem Einkaufsausschuss, der sich aus einem CFO, einem Beschaffungsmanager, einer IT-Director und einem Champion zusammensetzt, soll ein neues Produkt vorgeschlagen werden. Rollenspiele mit mehreren Personen unterstützen **bis zu vier Personen** in einem einzelnen Szenario.

1. Wählen Sie **Rollenspiel mit mehreren Personen** als Vorlage aus, wenn Sie das Rollenspiel starten.
2. Fügen Sie jede Person hinzu und weisen Sie ihr eine eigene Rolle zu. Beispiel: CFO, Procurement Manager, IT Director und Champion.
3. Konfigurieren Sie eine separate Persönlichkeit für jede Person, indem Sie die gleichen **AI-Personendetails**, wie oben beschrieben, ausführen.
4. Definieren Sie eindeutige Bedenken für jede Person, indem Sie dieselbe in **Persona-Bedenken beschriebene Bedenken-Struktur verwenden.** Jede Person stellt Fragen und erhebt Einwände aus ihrer eigenen Perspektive. Daher muss der Teilnehmer seine Botschaft für jeden Stakeholder der Reihe nach anpassen, anstatt einen allgemeinen Pitch zu geben.

## Konfigurieren der Konversationseröffnung

Der Abschnitt **Konversationseröffnung** steuert die ersten beiden Dinge, die ein Teilnehmer hört, wenn eine Simulation beginnt: eine kurze Erklärung des AI-Trainers, gefolgt von der ersten Zeile der AI-Person.

![](/help/migrated/authors/feature-summary/assets/virtual_coach5.png)
*Der AI-Trainer legt zuerst die Bühne fest, dann öffnet die AI-Person die Unterhaltung im Zeichen.*

**AI Trainer Opener** ist eine kurze Nachricht, die vom Trainer gesprochen wird, nicht die Person, bevor die Unterhaltung beginnt. Es teilt dem Teilnehmer mit, mit wem er sprechen wird, was das Ziel ist und welchen relevanten Kontext er einnehmen muss. Wählen Sie **Bearbeiten**, um den Text zu aktualisieren. Fasst euch kurz und direkt. Geben Sie bei anspruchsvolleren Szenarien das Ziel explizit an, z. B.: &quot;Sie sind dabei, einen kühlen Anruf bei einem leitenden Beschaffungsleiter zu tätigen. Ihr Ziel ist es, ein Follow-up-Meeting sicherzustellen.&quot;

**AI Persona Opener** ist die erste Zeile, die die AI Persona an den Teilnehmer übermittelt, um die Konversation zu starten. Es sollte die Persönlichkeit der Person widerspiegeln und den Teilnehmer vom ersten Austausch an vor Ort bringen. Wählen Sie **Bearbeiten**, um den Text zu aktualisieren.

| Szenario | Beispielöffner |
|---|---|
| Cold Call | &quot;Hallo? Wer ist das?&quot; |
| Geplanter Ermittlungsaufruf | &quot;Hallo, vielen Dank, dass du die Hand ausstreckst. Was wolltest du heute besprechen?&quot; |
| Feedback-Unterhaltung | &quot;Hast du kurz Zeit? Ich wollte letzte Woche darüber reden.&quot; |
| Executive-Pitch | &quot;Ich habe nur zehn Minuten. Was hast du für mich?&quot; |

Wählen Sie **Vorschau** aus, um die Wiedergabe der beiden Öffnen nacheinander zu hören, genau so, wie sie der Teilnehmer zu Beginn einer Sitzung erlebt.

>[!TIP]
>
>Wenn sich der Ton des AI Trainer Openers und des AI Persona Openers zu ähnlich anfühlen, kann der Übergang zwischen ihnen verwirrend sein. Halten Sie den Ausbilderöffner neutral und lehrreich. der persönliche Öffner die Persönlichkeit tragen lässt.

## Konfigurieren von Themen und Bewertungskriterien

Im Abschnitt **Themen für Cover** wird definiert, was der Teilnehmer während der Simulation ansprechen muss und wie die AI die Leistung zu jedem Thema auswertet. Dies ist Ihre AI-Rollenspielbewertungsrubrik. Jedes Thema, das Sie hinzufügen, wird im Wissensbericht des Teilnehmers zu einer bewerteten Komponente.

**Bevor Sie beginnen:** Schließen Sie zuerst den Abschnitt **Simulation personalisieren** ab. Die KI nutzt Konversationskontext und persönlichen Hintergrund, um präzise Bewertungsrichtlinien für jedes Thema zu erstellen.

Jede Zeile in der Thementabelle stellt einen erforderlichen Unterhaltungsbereich dar:

| Spalte | Zweck |
|---|---|
| Thema | Der Name des Konversationsbereichs, den der Teilnehmer abdecken muss |
| Bewertungsrichtlinien | die Kriterien, anhand derer die KI beurteilt, ob das Thema angemessen behandelt wurde; Diese Richtlinien werden auch als Feedback auf der Analyseseite des Teilnehmers angezeigt |
| Stärke | Der Prozentsatz der Wissensbewertung, zu der dieses Thema beiträgt; Alle Themengewichte müssen 100 % betragen |
| Beispielvideo | Ein optionales Video, das der Teilnehmer auf seiner Analyseseite ansehen kann, um zu sehen, wie das Thema behandelt werden sollte |
| Hilfreicher Link | Eine optionale URL, die auf der Analyseseite des Teilnehmers neben den Bewertungskriterien angezeigt wird |
| Erstellen oder Unterbrechen | Wenn diese Option aktiviert ist und der Teilnehmer dieses Thema überhaupt nicht anspricht, beträgt die Endpunktzahl der Simulation 0, unabhängig von der Leistung in anderen Themen. |

![](/help/migrated/authors/feature-summary/assets/virtual_coach6.png)
*Jede Themenzeile definiert, was ausgewertet werden soll, wie viel sie wert ist und ob sie übergeben werden muss.*

### Hinzufügen eines Themas

1. Wählen Sie im Abschnitt **Themen für Deckblatt** die Option **Bearbeiten** aus, um die Thementabelle zu öffnen.
2. Wählen Sie **Thema hinzufügen**. Eine neue Zeile wird mit leeren Feldern angezeigt.
3. Geben Sie den Themennamen in das Feld **Thema** ein. Verwenden Sie eine kurze, beschreibende Beschriftung, die den Unterhaltungsbereich widerspiegelt, z. B. `Opening and Rapport`, `Handling Objections` oder `Agreeing Next Steps`.
4. Geben Sie die Bewertungsrichtlinien im Feld **Bewertungsrichtlinien** ein. Schreiben Sie diese als Abschlussanweisung, die mit &quot;Um dieses Thema erfolgreich abzudecken, muss der Teilnehmer ...&quot; beginnt.
5. Geben Sie einen Prozentwert in das Feld **Gewicht** ein. Verteilen Sie die Gewichtungen auf alle Themen, sodass die Summe 100 % beträgt.
6. Wählen Sie optional **Klicken Sie, um Video hinzuzufügen**, um ein Beispielvideo anzuhängen, oder **Klicken Sie, um URL hinzuzufügen**, um einen hilfreichen Link anzuhängen, z. B. einen Knowledge Base-Artikel oder einen One Pager für ein Produkt.
7. Aktivieren Sie optional **Make oder Break** für nicht verhandelbare Themen.
8. Wiederholen Sie den Vorgang für jedes Thema, das Sie einschließen möchten, und wählen Sie dann **Fertig**.

### Bearbeiten oder Entfernen von Themen

- Um ein Feld in einer vorhandenen Themenzeile zu bearbeiten, wählen Sie das Feld direkt aus und aktualisieren Sie den Text oder Wert.
- Um die Evaluierungsrichtlinien mithilfe von KI anhand Ihrer Person und Ihres Kontexts neu zu generieren, wählen Sie das Aktualisierungssymbol (**↻**) in der Zelle **Evaluierungsrichtlinien**.
- Um ein Thema zu entfernen, wählen Sie das Optionsmenü (**⋮**) am Ende der Zeile aus und wählen Sie **Thema löschen**.
- Um ein Thema zu duplizieren und es als Grundlage für ein ähnliches Thema zu verwenden, wählen Sie **Thema duplizieren** aus demselben Menü aus.

### Richtlinien zum Verfassen effektiver Themen

Eine starke Bewertungsrubrik für KI-Rollenspiele macht den Unterschied zwischen einem Rollenspiel, das fair ist, und einem, das willkürlich ist. Beachten Sie die folgenden Richtlinien:

- **Benennen Sie Themen nach den Gesprächsphasen, nicht nach Produktfunktionen.** Themen wie `Opening and Rapport`, `Needs Discovery` und `Agreeing Next Steps` spiegeln die Struktur einer echten Unterhaltung wider.
- **Schreibe Bewertungsrichtlinien als beobachtbare Aktionen.** Die KI bewertet, was der Teilnehmer sagte. Richtlinien müssen also ein bestimmtes, hörbares Verhalten beschreiben und keine Absichten. Vergleichen Sie &quot;Der Teilnehmer sollte die Bedenken der Person verstehen&quot; (schwach) mit &quot;der Teilnehmer muss die Person bitten, ihre primäre Sorge zu benennen und zu bestätigen, dass sie sie gehört hat, bevor er antwortet&quot; (stark).
- **Verwenden Sie &quot;Make&quot; oder &quot;Break&quot; sparsam.** Reservieren Sie es für ein oder zwei Themen, bei denen die Unterhaltung durch völlige Unterlassung eindeutig scheitern würde, z. B. wenn Sie sich nicht in einem &quot;Cold Call&quot; vorstellen. Wenn es auf zu viele Themen angewendet wird, ist es für die Teilnehmer schwierig, auch nur einen vernünftigen Versuch zu bestehen.
- **Abwägen von Gewichtungen, um die Bedeutung der Unterhaltung widerzuspiegeln.** Ein Thema, das den größten Teil einer typischen Konversation einnimmt, z. B. die Ermittlung des Bedarfs in einem Verkaufsgespräch, sollte ein höheres Gewicht haben als ein kurzer Öffner oder ein kurzer Abschluss.
- **Hilfreiche Links zu Themen mit niedriger Punktzahl hinzufügen.** Wenn die Teilnehmer in einer Sitzung zu einem bestimmten Thema durchweg schlecht abschneiden, hängen Sie einen Ressourcenlink an, damit sie zwischen den Versuchen etwas lernen können.

## Spracheinstellungen konfigurieren

Der Abschnitt **Spracheinstellungen** steuert, ob Teilnehmer die Sprache auswählen können, in der sie beim Starten der Simulation üben. **Teilnehmern die Auswahl ihrer Übungssprache ermöglichen**, damit jeder Teilnehmer zu Beginn der Sitzung seine bevorzugte Sprache auswählen kann. Lassen Sie diese Option deaktiviert, wenn alle Teilnehmer in der Sprache üben sollen, in der das Rollenspiel erstellt wurde - die empfohlene Einstellung für formelle Bewertungen, bei denen die Sprachkonsistenz Teil der Bewertungskriterien ist.

>[!NOTE]
>
>Virtual Coach unterstützt Simulationsinhalte in neun Sprachen. Die Auswahl der Teilnehmersprache ist nur dann sinnvoll, wenn der Inhalt und die Person Ihres Szenarios so geschrieben sind, dass sie mehrsprachig verwendet werden kann. Wenn Ihre Bewertungsrichtlinien und Ihr persönlicher Hintergrund in einer einzigen Sprache verfasst sind, kann diese Einstellung zu inkonsistenten AI-Antworten für Teilnehmer führen, die eine andere Sprache auswählen.

## Aktionsanalyse auf dem Bildschirm konfigurieren

Im Abschnitt **Aktionsanalyse auf dem Bildschirm** können Sie ein Best-Practice-Video hochladen, das zeigt, wie die KI die Aktionen bewertet, die ein Teilnehmer während der Rollenspiele ergreift. Dies ist am nützlichsten für Simulationen, in denen vom Teilnehmer erwartet wird, dass er bestimmte Aktionen auf dem Bildschirm sichtbar demonstriert, z. B. das Navigieren in einer Software-Benutzeroberfläche, das Ausfüllen eines Formulars oder das Befolgen eines definierten Prozesses Schritt für Schritt.

>[!NOTE]
>
>Diese Option ist deaktiviert, wenn Sie nur PowerPoint- oder PDF-Dateien im Abschnitt **Präsentationseinstellungen** hochgeladen haben.

1. Wählen Sie &quot;**Datei auswählen**&quot; aus, um den Dateibrowser zu öffnen.
2. Wählen Sie Ihre Videodatei aus und bestätigen Sie den Upload.
3. Nach dem Hochladen wird der Dateiname in der Zusammenfassungszeile **Aktionsanalyse auf dem Bildschirm** angezeigt.

Für Ihr Video müssen die folgenden Anforderungen erfüllt sein:

| Anforderung | Spezifikation |
|---|---|
| Dateiformat | WEBM, MP4, WMV oder MPEG |
| Maximale Dateigröße | 200 MB |
| Mindestauflösung | 1280 x 720 Pixel |
| Mindest-Rahmen | 5 FPS |
| Seitenverhältnis | Zwischen 4:3 und 21:9 |

Wenn Sie ein Best-Practice-Video aufnehmen, beschreiben Sie alle Aktionen in Audio und auf dem Bildschirm gleichzeitig. Sagen Sie dabei beispielsweise &quot;Ich wähle jetzt die Schaltfläche zum Senden&quot;, da AI sowohl auf dem Kommentar als auch auf der visuellen Aktion basiert. Konzentrieren Sie sich bei der Aufzeichnung auf die Aufgabe, entfernen Sie Benachrichtigungen und nicht zugehörige Inhalte, und stimmen Sie das Video mit Ihren Auswertungsrichtlinien ab, damit jede erforderliche Aktion an der Stelle im Arbeitsablauf veranschaulicht wird, an der sie erwartet wird.

## Konfigurieren der Punktpunktzahleinstellungen

**Mindestpunktzahl für Bestehen** ist die Mindestgesamtpunktzahl, die ein Teilnehmer erreichen muss, damit die Simulation als bestanden markiert und auf die gewichtete Kombination aus Kenntnisstand und Stilpunktzahl angewendet wird. Geben Sie im Feld **Bestanden der Punktzahl** eine Zahl zwischen 1 und 100 ein (der Standardwert ist 80) und wählen Sie **Fertig**.

>[!TIP]
>
>Bei formellen Bewertungen ist ein Mindestwert zum Bestehen der Prüfung 75 bis 80 typisch. Bei Rollenspielen im Übungsmodus, bei denen das Ziel nicht die Zertifizierung, sondern die Entwicklung von Fertigkeiten ist, sollten Sie einen niedrigeren Schwellenwert berücksichtigen oder **Übungsmodus** aktivieren.

**AI-Bewertungsgewichte** legen fest, wie viel die Wissenskomponente (ob der Teilnehmer erforderliche Themen abgedeckt und genaue Informationen angegeben hat) und die Stilkomponente (Tempo, Klarheit, Füllwörter, Satzlänge, Energie) jeweils zur Gesamtpunktzahl beitragen. Verschieben Sie den Regler, um die Balance anzupassen. Die beiden Werte ergeben immer einen Gesamtwert von 100 %, und der Standardwert ist Wissen 70 % / Stil 30 %. Hinweise dazu, wie Teilnehmer diese Punktzahlen interpretieren, finden Sie unter [Verstehen des Leistungsberichts Ihres virtuellen Coaches](/help/migrated/learners/feature-summary/virtual-coach/understand-virtual-coach-performance-report.md).

| Szenariotyp | Empfohlene Kennzahl | Ursache |
|---|---|---|
| Kompetenzbewertung oder Zertifizierung | 80 % Wissen / 20 % Stil | Die inhaltliche Genauigkeit ist die wichtigste Messgröße. |
| Verkaufsförderung | 60 % Wissen / 40 % Stil | Die Bereitstellung ist genauso wichtig wie die Kommunikation mit Kunden. |
| Führungskräfteentwicklung | 70 % Wissen / 30 % Stil | Ausgewogen - Inhalt und Stil sind bei Gesprächen mit Kunden entscheidend |
| Kommunikationscoaching | 40 % Wissen / 60 % Stil | Stil ist das wichtigste Lernziel |

Mit **Übungsmodus für Teilnehmer aktivieren** können Teilnehmer während der Simulation Hinweise anfordern, um ihnen zu helfen, auf Kurs zu bleiben - nützlich für das Lernen in der Frühphase. Wenn diese Option aktiviert ist, können Sie **Max. Hinweise pro Sitzung** (Standard 5, einstellbar von 1-10) und die Dauer der Hinweissichtbarkeit (Standard 30 Sekunden) festlegen.

>[!NOTE]
>
>Während der formellen Bewertung sind keine Hinweise verfügbar. Wenn Sie dieses Rollenspiel als abgestufte Bewertung verwenden, deaktivieren Sie den Übungsmodus, damit alle Teilnehmer unter den gleichen Bedingungen bewertet werden.

**Punktzahl ausblenden** verhindert, dass Teilnehmer ihre numerische Punktzahl nach der Sitzung sehen; Sie erhalten weiterhin qualitatives Feedback und Analysen auf Themenebene. Verwenden Sie diese Option, wenn das Rollenspiel nur zum Üben dient, wenn nur ein Manager-Bewerter das Ergebnis sehen sollte oder wenn Sie die Punkteangst in frühen Lernphasen verringern möchten.

## Erweiterte Rollenspieleinstellungen konfigurieren

Diese optionalen Einstellungen steuern, wie und wann die Simulation endet und wie die Sitzungsumgebung konfiguriert wird.

**Zulassen, dass die AI die Rollenwiedergabe beendet.** Standardmäßig kann nur der Teilnehmer eine Simulation beenden, indem er **Simulation beenden** auswählt. Aktivieren Sie diesen Schalter und beschreiben Sie die Bedingung, unter der die Person die Unterhaltung natürlich schließen soll, z. B.: &quot;Wenn der Teilnehmer erfolgreich ein Follow-up-Meeting ansetzt oder die Person dreimal ablehnt, sollte die Person den Anruf höflich beenden.&quot; Verwenden Sie dies für erweiterte Szenarien, bei denen der natürliche Endpunkt der Unterhaltung, nicht ein Timer, bestimmen sollte, wann die Sitzung geschlossen wird.

**Zeitlimit für Simulation.** Geben Sie einen Wert zwischen 1 und 59 Minuten ein, um eine maximale Sitzungsdauer festzulegen. Wenn diese erreicht ist, endet die Simulation automatisch und der Teilnehmer wird zur Analyseseite geleitet.

| Szenariotyp | Empfohlene Höchstgrenze |
|---|---|
| Kaltruf oder kurze Einführungspraxis | 3-5 Minuten |
| Ermittlung des Anrufs oder der Bedarfsermittlung | 10-15 Minuten |
| Umfassende Verkaufsgespräche oder Führungsgespräche | 15-20 Minuten |
| Formelle Bewertung mit mehreren Themen | Die erwartete Gesprächslänge in der realen Welt erreichen. |

**Strafe für kurze Sitzungen** hält Teilnehmer davon ab, Sitzungen zu schnell zu beenden, indem sie eine Punktereduzierung anwenden, wenn die Sitzung eine von Ihnen festgelegte Mindestdauer unterschreitet. Verwenden Sie diese Option, wenn die Sitzungslänge für das Lernziel aussagekräftig ist. Zum Beispiel in einem Discovery-Call, bei dem der Teilnehmer genügend Zeit aufwenden muss, um die Anforderungen zu ermitteln, bevor er eine Lösung vorschlägt.

>[!NOTE]
>
>Verwenden Sie die Strafe für kurze Sitzungen nicht in Rollenspielen im Übungsmodus, bei denen die Teilnehmer noch Vertrauen aufbauen, da die Bestrafung früher Ausstiege die Angst verstärken und wiederholte Versuche abschrecken kann.

Mit **Bildschirmfreigabe aktivieren** können Teilnehmer ihren Bildschirm während der Simulation freigeben. Dies ist für Szenarien relevant, die eine **On-Screen-Aktionsanalyse**-Komponente enthalten. Sie ist standardmäßig deaktiviert, wenn Sie nur PowerPoint- oder PDF-Dokumente in **Präsentationseinstellungen** hochgeladen haben.

**KI-Untertitel aktivieren** zeigt auf dem Bildschirm den Text der KI-Person in Echtzeit an. Aktivieren Sie diese Option für Teilnehmer mit Hörproblemen oder für das Üben in einer Zweitsprache, für laute Umgebungen oder für Szenarien, in denen das Lesen der genauen Wörter der Person wichtig ist, um nuancierte Einwände zu verstehen.
