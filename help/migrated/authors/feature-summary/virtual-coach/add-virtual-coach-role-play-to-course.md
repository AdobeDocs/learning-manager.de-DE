# Hinzufügen eines virtuellen Coach-Rollenspiels zu einem Kurs

Publish bietet einen virtuellen Coach als Rollenspiel als Arbeitshilfe und fügt diesen dann einem Kurs hinzu, damit die Teilnehmer im Rahmen einer strukturierten Lernreise darauf zugreifen können.

Rollenspiele für virtuelle Coaches werden nicht direkt zu Kursen hinzugefügt. Stattdessen veröffentlichen Sie das Rollenspiel zunächst als Arbeitshilfe und fügen diese Arbeitshilfe dann einem Kurs als Modul hinzu. Mit diesem zweistufigen Prozess können Sie dasselbe Rollenspiel über mehrere Kurse hinweg wiederverwenden, ohne es zu duplizieren. Im Rahmen der Haube wird ein veröffentlichtes Rollenspiel Ihrer Inhaltsbibliothek als LTI-Modul hinzugefügt, sodass es entweder als eigenständige Arbeitshilfe oder als Kursmodul bereitgestellt werden kann. Bevor Sie beginnen, [erstellen und veröffentlichen Sie ein virtuelles Coach-Rollenspiel](/help/migrated/authors/feature-summary/virtual-coach/create-publish-virtual-coach-role-play.md), falls Sie dies noch nicht getan haben.

## Rollenspiel als Arbeitshilfe hinzufügen

1. Wählen Sie im linken Navigationsbereich auf der Startseite des Autors **Arbeitshilfen**.
2. Wählen Sie in der oberen rechten Ecke **Erstellen** > **Virtueller Coach** aus.
3. Geben Sie einen Namen und eine Beschreibung für die Arbeitshilfe ein.
4. Wählen Sie im Feld **Virtuellen Coach suchen und auswählen** das Rollenspiel **Virtueller Coach** aus, das Sie verwenden möchten.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach8.png)
   *Suchen Sie nach dem veröffentlichten Rollenspiel, das Sie in eine Arbeitshilfe umwandeln möchten, und wählen Sie es aus.*

5. Sichtbarkeit festlegen:
   - Behalten Sie die Standardeinstellung **Freigegeben** bei, damit andere Autoren diese Arbeitshilfe ihren Kursen zuweisen können.
   - Wählen Sie **Privat**, um den Zugriff auf Ihre eigenen Kurse einzuschränken.
6. Optional können Sie die erwartete Abschlusszeit in Minuten in das Feld **Dauer** eingeben.
7. Geben Sie im Feld **Tags** Schlüsselwörter ein, um die Arbeitshilfe in der Suche und im Katalog sichtbar zu machen.
8. Optional können Sie Kenntnisse und Kenntnisstufen zuweisen. Es können nur Kenntnisse verwendet werden, die bereits in Ihrem Adobe Learning Manager-Konto vorhanden sind. auf diesem Bildschirm können keine Kenntnisse erstellt werden, und ihre Zuweisung ist nicht obligatorisch.
9. Wählen Sie **Speichern**. Die Arbeitshilfe wird veröffentlicht und kann zu einem Kurs hinzugefügt werden.

## Rollenspiel zu einem Kurs hinzufügen

Sobald die Arbeitshilfe veröffentlicht wurde, fügen Sie sie einem beliebigen Kurs als Modul hinzu. Das Rollenspiel wird den Teilnehmern als Teil der Kurssequenz neben anderen Inhalten wie Videos, Dokumenten oder Tests angezeigt.

1. Wählen Sie im linken Navigationsbereich der Autorenstartseite **Kurse**.
2. Öffnen Sie den Kurs, dem Sie das Rollenspiel hinzufügen möchten, oder wählen Sie **Erstellen** aus, um einen neuen Kurs zu starten. Wenn Sie einen vorhandenen Kurs öffnen, sollten Sie nach dem Öffnen **Bearbeiten** auswählen.
3. Fügen Sie den Kursnamen und die Beschreibung hinzu.
4. Navigieren Sie zum Abschnitt **Module** des Kurseditors.
5. Es gibt drei Abschnitte, in denen Sie Module hinzufügen können. Wenn Sie einen virtuellen Coach auswählen möchten, navigieren Sie zum ersten Abschnitt mit dem Namen **Inhalt**, wählen Sie **Modul hinzufügen** aus, und wählen Sie dann **Virtueller Coach** aus.

   ![](/help/migrated/authors/feature-summary/assets/virtual-coach18.png)

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach9.png)
   *Wählen Sie &quot;Virtueller Coach&quot; als Modultyp aus, um Ihr veröffentlichtes Rollenspiel einem Kurs hinzuzufügen.*

6. Suchen Sie nach dem virtuellen Coach-Rollenspiel, das Sie erstellt haben, und wählen Sie es aus.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach10.png)
   *Suchen Sie die Arbeitshilfe anhand des Namens oder Tags und aktivieren Sie dann das entsprechende Kontrollkästchen, um sie dem Kurs hinzuzufügen.*

7. Wählen Sie **Hinzufügen** aus.
8. Konfigurieren Sie die Abschluss- und Erfolgskriterien des Moduls entsprechend Ihrem Kursdesign.
9. Wählen Sie **Neu veröffentlichen**, wenn Sie einen vorhandenen Kurs aktualisiert haben. Wenn Sie einen vorhandenen Kurs aktualisiert haben, wird nur die Schaltfläche **Neu veröffentlichen** angezeigt. Wählen Sie **Speichern**, wenn Sie den Kurs neu erstellt haben. Sie sehen nur die Schaltfläche **Speichern**, wenn Sie den Kurs neu erstellt haben. Durch Klicken auf die Schaltfläche **Speichern** wird der Kurs auf der Seite &quot;Kurskatalog&quot; auf der Registerkarte **Entwurf** gespeichert. Um denselben Kurs zu veröffentlichen, navigieren Sie auf der Seite **Kurskatalog** zu demselben Kurs, wählen Sie die Auslassungspunkte aus und wählen Sie **Publish-Kurs** aus.

   ![](/help/migrated/authors/feature-summary/assets/virtual-coach19.png)

>[!NOTE]
>
>Alle Aktualisierungen, die Sie an der Arbeitshilfe vornehmen, einschließlich Änderungen am Rollenspielinhalt, werden automatisch in allen Kursen widergespiegelt, denen sie hinzugefügt wurde. Wenn das Rollenspiel Teil einer formalen Bewertung ist, veröffentlichen Sie die Arbeitshilfe erneut, nachdem Sie Änderungen vorgenommen haben, damit die Teilnehmer die neueste Version sehen.

## Virtuellen Coach im Rahmen einer Lernreise verpacken

Der virtuelle Coach ist so konzipiert, dass er am besten als &quot;letzte Meile&quot; des Trainings funktioniert - der Punkt, an dem die Teilnehmer zeigen, dass sie das, was sie gerade gelernt haben, anwenden können, anstatt eine eigenständige Aktivität durchzuführen. Verpacken Sie die Rollenspiele in einem Kurs oder auf einer Lernreise neben den entsprechenden Inhalten und verteilen Sie den Kurslink per E-Mail oder andere Mitteilungen zum Änderungsmanagement, sodass die Teilnehmer genau wissen, wann und warum sie den Kurs abschließen sollen.

Dieser Verpackungsansatz eignet sich gut für mehrere gängige Rollouts:

- **Onboarding neuer Mitarbeiter und Ramp-up**, bei dem das Rollenspiel dem Onboarding von Inhalten folgt und bestätigt, dass ein neuer Mitarbeiter für seine erste Live-Unterhaltung bereit ist.
- **Vertriebszertifizierung und -verstärkung**, wobei das Rollenspiel der Zertifizierungs-Checkpoint am Ende eines Verkaufsunterstützungskurses ist.
- **Bereitschaft zur Produkteinführung**, wobei das Rollenspiel der Schulung zur Produkteinführung folgt und bestätigt, dass Vertriebsmitarbeiter das neue Produkt positionieren können, bevor es auf den Markt kommt. Beispiel: Das Szenario zur Bereitschaft zur Produkteinführung, das in [Virtueller Coach ist](/help/migrated/authors/feature-summary/virtual-coach/what-virtual-coach-is.md) beschrieben wird, in dem ein Vertriebsmitarbeiter seine Position in einem persönlichen Einkaufskomitee anpassen muss.
- **Führungs- und Manager-Coaching**, wobei das Rollenspiel einem Management-Skills-Kurs folgt und einem echten Leistungsgespräch vorausgeht.
- **Partnerbereitschaftsprogramme**, bei denen das Rollenspiel bestätigt, dass ein externer Partner Ihr Produkt korrekt darstellen kann, bevor es zertifiziert wird.
- **Management- und Kommunikationsschulung ändern**, wobei das Rollenspiel einen neuen Prozess oder eine neue Organisationsnachricht verstärkt, nachdem die Mitarbeiter verwandte Inhalte abgeschlossen haben.

Sobald die Teilnehmer das Rollenspiel finden und starten können, finden Sie weitere Informationen unter [Üben eines Rollenspiels mit dem virtuellen Coach](/help/migrated/learners/feature-summary/virtual-coach/practice-role-play-with-virtual-coach.md).
