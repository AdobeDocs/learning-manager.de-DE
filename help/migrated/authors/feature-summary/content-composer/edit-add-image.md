# Bild bearbeiten oder hinzufügen

![](../assets/16_hierarchy_of_controls_eliminate_substitute_updated.png)

Wählen Sie ein beliebiges Bild aus, um die Bildsymbolleiste zu öffnen. Folgende Optionen stehen zur Auswahl:

- **Füllen**, **Einpassen:**, wie das Bild innerhalb seines Rahmens skaliert wird

- **Alt-Text** Feld: zeigt die Bildbeschreibung an.<br>
  **Hinweis**: Dieser Text kann nicht geändert werden. Er wird automatisch basierend auf dem Bild aktualisiert.

- Symbol **Weitere Optionen**: **passt** Helligkeit, Sättigung und Transparenz des Bildes an.

Um das Bild zu ersetzen, wählen Sie das Symbol **Bild** aus, um das Bild zu ändern. Du kannst deine eigene Datei hochladen, nach Adobe Stock suchen oder eine Datei mit KI generieren.
