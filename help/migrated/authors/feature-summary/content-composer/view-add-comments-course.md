# Kurs anzeigen und Kommentare hinzufügen

Wenn Sie der Kursersteller sind, wählen Sie den Bereich **Kommentare** in Ihrem Projekt aus, um Kommentare anzuzeigen und darauf zu antworten.

1. **Kommentarbereich öffnen**: &quot;**Kommentare**&quot; aus der Symbolleiste auswählen. Im Kommentarbereich werden die vom Reviewer bereitgestellten Kommentare angezeigt.

2. Sie können die Kommentare als geklärt markieren oder bearbeiten bzw. löschen.

3. Nehmen Sie die erforderlichen Änderungen vor, und **Speichern** Sie das Projekt.

4. Wählen Sie in der Symbolleiste &quot;**Freigeben**&quot; aus, um den neuesten Link zu aktualisieren.
