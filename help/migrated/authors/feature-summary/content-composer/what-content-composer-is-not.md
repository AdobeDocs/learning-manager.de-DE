# Was Adobe Learning Manager Content Composer nicht ist

So stellen Sie vor dem Start präzise Erwartungen ein:

- Content Composer unterstützt keine Verzweigungen oder adaptive Lernpfade. Kurse folgen einer linearen Lektion > Themenstruktur.

- Das Quiz am Ende der Lektion unterstützt nur Multiple-Choice-Fragen und True-/False-Fragen in der aktuellen Beta-Version. Weitere Fragetypen sind in der Roadmap enthalten.

## Nächste Schritte

Wenn Sie beginnen möchten, finden Sie unter [Erstellen eines Kurses mit Content Composer](#create-course) den vollständigen Schritt-für-Schritt-Arbeitsablauf.

**App testen**. Öffnen Sie [**Content Composer**](https://contentcomposer.adobe.io/) und folgen Sie der schrittweisen Anleitung.

Wenn Probleme auftreten, wenden Sie sich an den Support oder senden Sie Ihre Fragen an die [Adobe Learning Manager-Community](https://community.adobe.com/adobe-learning-manager-466).
