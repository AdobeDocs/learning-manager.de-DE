# Exportieren eines Designs

Exportieren Sie ein Design als JSON-Datei, um es außerhalb von Content Composer anzupassen oder es für andere Autoren freizugeben.

1. Wählen Sie **Designs** in der Symbolleiste aus, um den Bereich **Kursdesigns** zu öffnen.

2. Bewegen Sie den Mauszeiger über das Design, das Sie exportieren möchten, und wählen Sie das Symbol **Exportieren** aus.
   ![](../assets/47_export_theme_save_as_json_dialog_updated.png)

3. Wählen Sie im angezeigten Dialogfeld einen Speicherort aus, geben Sie einen **Dateinamen ein.**
