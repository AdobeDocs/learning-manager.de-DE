# Was ist Adobe Learning Manager Content Composer?

Adobe Learning Manager Content Composer kombiniert die Erstellung von Kursen in einem einzigen KI-gestützten Workflow. Sie beschreiben, was Sie unterrichten möchten, und das Produkt generiert basierend auf Ihren Eingaben eine strukturierte Gliederung und einen vollständigen Kursinhalt, einschließlich Bildern, Wissensüberprüfungen und einem abgestuften Quiz.

Content Composer führt alle Phasen der Lernerstellung in einem einzigen Workflow ein und unterstützt die gemeinsame Erstellung mit KI, die das didaktische Design versteht. So könnt ihr Lernen erstellen, das nicht nur schneller zu erstellen ist, sondern durch Design auch effektiver wird.

Wenn Ihr Kurs fertig ist, können Sie:

- Publish-Kurse werden direkt an Adobe Learning Manager weitergegeben. Umfassende Teilnehmeranalysen bieten verwertbare Einblicke in die Lerneffektivität.
- Laden Sie es als SCORM-Paket herunter, um es in einem kompatiblen LMS zu verwenden.
