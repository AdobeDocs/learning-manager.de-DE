# Festlegen des Hell- oder Dunkelmodus für den Kurs

<!--Select **light/dark** mode in the toolbar to toggle between modes. Content Composer updates the canvas to reflect the selected mode.-->

Wählen Sie [!UICONTROL Kontomenü] > [!UICONTROL Design anwenden] > Hell- oder Dunkelmodus aus. Der Inhalts-Composer aktualisiert die Arbeitsfläche, um den ausgewählten Modus widerzuspiegeln.
