# Bearbeiten der Kursübersicht

![](../assets/10_outline_tab_generated_lessons_topics_updated.png)

Adobe Learning Manager Content Composer generiert eine Lektion und eine Themenstruktur aus Ihren Brief- und Quelldateien. Die Gliederung wird auf der Arbeitsfläche mit allen Lektionen und ihren Themen angezeigt.

**Hinweis:** Die Bearbeitung der Gliederung ist derzeit in der Betaversion konversativ. Sie können auf der Arbeitsfläche keine Lektion oder kein Thema auswählen, um sie umzubenennen oder neu zu ordnen. Geben Sie Ihre Änderung als einfache Sprachanforderung im Chat-Bedienfeld ein.

Der Assistent arbeitet im Gespräch. Sie können Anfragen in Ihren eigenen Worten formulieren. Im Folgenden finden Sie einige Beispiele für Aktionen, die Sie ausführen können:

| **Aktion** | **Beispielanforderung** |
|--------------------------|---------------------------------------------------------------------------|
| Umbenennen von Lektionen oder Themen | &quot;Benennen Sie Lektion 1 in &#39;Wie Phishing funktioniert&#39; um&quot; |
| Lektion oder Thema hinzufügen | &quot;Fügen Sie Lektion 2 ein Thema zum Phishing von QR-Code hinzu&quot; |
| Lektion oder Thema löschen | &quot;Thema 1.3 entfernen&quot; |
| Eine Lektion teilen | &quot;Lektion 3 in zwei Teile teilen. Einer für Spam-Filter, einer für die Patch-Verwaltung.&quot; |
| Lektionen zusammenführen | &quot;Lektion 3 und 4 in einer Lektion zusammenfassen&quot; |
| Umriss neu generieren | &quot;Neuerstellung mit mehr Fokus auf Kennworthygiene&quot; |

Verwenden Sie einfache Sprachanfragen im Chat-Bereich, um Lektionen, Themen oder die gesamte Gliederungsstruktur zu ändern.

Die Gliederungshierarchie wurde als Lektionen > Themen festgelegt. Sie können keine Unterthemen oder Strukturen auf drei Ebenen erstellen.

Wenn die Gliederung richtig angezeigt wird, wählen Sie **Kurs generieren** in der oberen Symbolleiste aus.
