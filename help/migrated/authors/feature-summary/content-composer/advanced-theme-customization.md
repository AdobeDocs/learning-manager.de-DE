# Erweiterte Anpassung des Designs im Inhalts-Composer

## Erweiterte Designeigenschaften in der App anpassen

Verwenden Sie erweiterte Designeigenschaften, um die einzelnen Elemente genauer zu steuern, z. B. Lektionsnamen, Themennamen, Blocküberschriften, Unterüberschriften, Beschriftungen und Absätze.

1. Wählen Sie **Designs** aus, bewegen Sie den Mauszeiger über das angewendete Design, wählen Sie **Bearbeiten** aus, und wählen Sie dann **Erweitert** aus.
   ![Die Schaltfläche &quot;Erweitert&quot; im Bereich &quot;Design bearbeiten&quot;](../assets/41_edit_theme_advanced_button_updated.png)

2. Legen Sie im Bereich &quot;Schrifteigenschaften&quot; die **Schriftpaarung** für Ihren Kurs fest:

   - Wählen Sie das Dropdown-Menü **Überschriften** aus, und wählen Sie eine Schriftart für alle Überschriften aus.

   - Wählen Sie die Dropdown-Liste **Haupttext** aus und wählen Sie eine Schriftart für den Haupttext aus.
     ![Die Registerkarte &quot;Schriftarteigenschaften&quot; der erweiterten Designeigenschaften mit Optionen für die Schriftartpaarung](../assets/42_advanced_theme_properties_font_pairing_updated.png)

3. Liste der Elemente festlegen: **Lektionsname**, **Themenname**, **Blocküberschrift**, **Unterüberschrift**, **Beschriftung** und **Absatz;** wählen das Element aus, das Sie anpassen möchten.

4. Im Bereich [!UICONTROL Visuelle Eigenschaften] können Sie Layout und Abstand im Kurs anpassen.

   - Legen Sie den Abstand zwischen Elementen mithilfe der Optionen für die Inhaltsdichte fest.

   - Um **Eckenradius von Karten/Bildern** festzulegen, ziehen Sie den Schieberegler oder geben Sie einen Wert ein, um die Rundheit von Karten und Bildern festzulegen. Geben Sie beispielsweise für den Radius 17 Px ein.

   - Wählen Sie **Lektion**, um die Hintergrundfarbe oder das Hintergrundbild einer Lektion zu ändern.

   - Wählen Sie &quot;**Topic**&quot; aus, um die Hintergrundfarbe oder den Rahmen eines Themas festzulegen.

   - Wählen Sie **Kopf-/Fußzeile** aus, um die Kopf- und Eigenschaften festzulegen.

   Content Composer zeigt automatisch Ihre Änderungen auf der Arbeitsfläche an, während Sie sie vornehmen.

5. Passen Sie die Eigenschaften des ausgewählten Elements nach Bedarf an:

   - Wählen Sie einen **Schriftschnitt** aus, z. B. &quot;Groß-/Kleinschreibung&quot;.

   - Legen Sie die **Schriftgröße** mithilfe der Steuerelemente **+** und **-** fest.

   - Wählen Sie eine **Schriftfarbe** aus.

   - Wenden Sie Formatierungen wie **Bold**, *Italic*, <u>Underline</u> oder ~~Durchstreichen~~ an.

   - Legen Sie die **Textausrichtung** fest.

6. Auf der rechten Arbeitsfläche kannst du eine Vorschau deiner Änderungen anzeigen. Verwenden Sie die Registerkarten **Aktuelle Lektion** und **Lektion testen**, um zu überprüfen, wie Ihre Änderungen in verschiedenen Lektionen angezeigt werden.
   ![Die Vorschau der Testlektion in den erweiterten Designeigenschaften](../assets/43_advanced_theme_test_lesson_preview_updated.png)

7. Wählen Sie **Als neu speichern** oder **Speichern**.
