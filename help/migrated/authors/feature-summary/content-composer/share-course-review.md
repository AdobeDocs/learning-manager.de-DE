# Projekt zur Überprüfung freigeben

Mit Content Composer können Sie ein Projekt für Reviewer oder Teilnehmer freigeben, ohne dass diese die Anwendung installieren müssen. So erhalten Sie eine schnelle, strukturierte Möglichkeit, Feedback einzuholen und sich vor der Veröffentlichung von der Anwendung abmelden zu lassen.

Als Autor können Sie Reviewer per Name oder E-Mail einladen, genau steuern, wer Zugriff hat, und diesen Zugriff jederzeit widerrufen. Prüfer können den freigegebenen Link öffnen, Kommentare direkt zu einer Kurskomponente hinzufügen und sogar das endgültige Quiz durchführen, ohne die aufgezeichneten Punktzahlen zu verändern, sodass sie das gesamte Lernerlebnis der Teilnehmer in der Vorschau ansehen können.

Kommentare bleiben organisiert und umsetzbar: Reviewer und Eigentümer können über ein einziges Bedienfeld in Kommentaren antworten, klären, filtern und erwähnen, unabhängig davon, ob sie extern prüfen oder innerhalb des Projekts arbeiten. Sobald Sie das Feedback beantwortet und das Projekt aktualisiert haben.

So geben Sie ein Projekt für den Review frei:

1. Wählen Sie **Zur Überprüfung** aus.

   ![](../assets/54_share_document_who_has_access_editor.png)

2. Geben Sie die Namen oder E-Mail-Adressen der Überprüfer in das Feld **Personen einladen** ein.

   ![](../assets/55_invite_people_message_invite_as_commenter.png)
3. Überprüfen Sie, wer Zugriff hat, um zu bestätigen, dass nur eingeladene Personen auf das Projekt zugreifen können.

4. Wählen Sie **Als Kommentator einladen**, um Reviewer per Name oder E-Mail hinzuzufügen. Sie können beliebig viele Reviewer hinzufügen. Oder wählen Sie **Link kopieren** aus, um die Review-URL zu kopieren und direkt für Reviewer freizugeben, die bereits Zugriff haben. Dies sind zwei verschiedene Möglichkeiten, das Projekt freizugeben.

   ![](../assets/56_who_has_access_commenter_dropdown_remove.png)

## Zugriff eines Überprüfers entfernen

Sie können einen Reviewer aus der Liste der Personen entfernen, die Zugriff auf das Projekt haben. Wenn dieser Reviewer versucht, das Projekt über einen zuvor freigegebenen Link erneut zu öffnen.

Sie haben die Möglichkeit, einen ausgewählten Kommentator zu entfernen. Wenn ein Kommentator aus der Liste der Personen entfernt wird, die Zugriff auf das Dokument haben.

Zugriff entfernen:

* Wählen Sie den Namen des Überprüfers aus und wählen Sie aus den angezeigten Optionen Entfernen aus.

* Wenn der Reviewer versucht, mit einem zuvor freigegebenen Link auf das Dokument zuzugreifen. Die Meldung Zugriff verweigert wird angezeigt.

  ![](../assets/57_access_denied_switch_profile_request_access.png)

## Zugriff anfordern

Wenn Sie versuchen, ein freigegebenes Projekt zu öffnen, auf das Sie keinen Zugriff mehr haben, müssen Sie den Zugriff anfordern, bevor Sie es anzeigen können. Dies kann beispielsweise passieren, wenn der Eigentümer Sie entfernt hat oder wenn Sie den Link mit einer anderen Adobe ID öffnen. In beiden Fällen wird der Bildschirm Zugriff verweigert angezeigt.

* Wählen Sie **Zugriff anfordern**, um den Eigentümer um die Berechtigung zum Überprüfen des Projekts und zum Hinzufügen von Kommentaren zu bitten.

  ![](../assets/58_request_access_dialog_message_field.png)

* Der Projekteigentümer erhält eine Benachrichtigung mit dem Namen des Reviewers, der den Zugriff anfordert.
