# Design erstellen

Es gibt zwei Möglichkeiten, ein benutzerdefiniertes Design zu erstellen, wobei beide das Ergebnis zur Liste der **benutzerdefinierten** Designs hinzufügen:

- **Mit der Option** Erstellen **in der Symbolleiste von Grund auf neu erstellen** - Konfigurieren Sie die Farbpalette, die Schriften und andere Eigenschaften und **Speichern als neu**.

- **Eine benutzerdefinierte JSON-Datei importieren** - Exportieren Sie ein vorhandenes Design als JSON, bearbeiten Sie es in einem Text- oder Code-Editor und importieren Sie es dann wieder in den Editor.

**Sie benötigen mehr Kontrolle?**

Informationen zur Typografie pro Element (Lektionsnamen, Themennamen, Blocküberschriften, Beschriftungen), zur Anpassung auf Farb-Token-Ebene und zum vollständigen JSON-Schemazugriff - die Art der Steuerung, die eine Plattform oder ein Marken-Team normalerweise benötigt, finden Sie unter [Erweiterte Designanpassung](advanced-theme-customization.md).

## Erstellen eines neuen Designs

1. Wählen Sie in der Symbolleiste **Erstellen** aus, um das Bedienfeld **Kursthemen** zu öffnen.
   ![](../assets/44_course_themes_create_button_updated.png)

2. Konfigurieren Sie die Farbpalette, die Schriften und andere Eigenschaften des Themas nach Bedarf.
   ![](../assets/45_create_theme_panel_name_palette_fonts_updated.png)

3. Wählen Sie **Als neu speichern** aus, um das Design zur Liste der **benutzerdefinierten** Designs hinzuzufügen.
   ![](../assets/46_custom_themes_list_new_theme_added_updated.png)

## Erstellen eines Designs durch Importieren von JSON

1. Wählen Sie **Designs** in der Symbolleiste aus, um den Bereich **Kursdesigns** zu öffnen.

2. Bewegen Sie den Mauszeiger über das Design, das Sie als Basis verwenden möchten, und wählen Sie **Exportieren** aus, um es als JSON-Datei herunterzuladen.

3. Öffnen Sie die JSON-Datei in einem Text- oder Code-Editor und aktualisieren Sie ihre Eigenschaften, z. B. Radius, Abstand, Farbpalette oder Schriftarten.

4. Speichern Sie die JSON-Datei.

5. Wählen Sie im Inhaltskomposer im Bereich **Kursthemen** die Option **Importieren**.

6. Wählen Sie die aktualisierte JSON-Datei von Ihrem Computer aus.

7. Wählen Sie **Als neu speichern** aus, um das Design zur Liste der **benutzerdefinierten** Designs hinzuzufügen.
