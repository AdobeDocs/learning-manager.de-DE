# Quiz im abgesicherten Prüfungsbrowser starten

Safe Exam Browser (SEB) ist ein sicherer Browser, der eine kontrollierte Umgebung für Online-Bewertungen bietet. Adobe Learning Manager unterstützt den abgesicherten Prüfungsbrowser für Tests, die eine sichere Testumgebung erfordern. Wenn Sie ein Quiz auswählen, für das ein abgesicherter Prüfungsbrowser erforderlich ist, werden Sie von Adobe Learning Manager aufgefordert, den abgesicherten Prüfungsbrowser herunterzuladen oder zu starten, bevor Sie auf die Bewertung zugreifen können.

Der abgesicherte Prüfungsbrowser bietet eine eingeschränkte Umgebung für die Teilnahme an dem Quiz. Nach dem Start des sicheren Prüfungsbrowsers ist der Zugriff auf andere Browser und Anwendungen eingeschränkt und aktive Aufrufe werden getrennt.

Der sichere Prüfungsbrowser ist nur für das ausgewählte Quiz erforderlich und wirkt sich nicht auf andere Kursmodule wie virtuelle Klassenzimmersitzungen aus.

In diesem Artikel wird erläutert, wie Sie den abgesicherten Prüfungsbrowser herunterladen, von Adobe Learning Manager aus starten und auf das Quiz zugreifen.

**Abgesicherten Prüfungsbrowser herunterladen**

Wenn der abgesicherte Prüfungsbrowser auf Ihrem Gerät noch nicht installiert ist, führen Sie die folgenden Schritte aus, um ihn herunterzuladen und zu installieren:

1. Öffnen Sie den Kurs und wählen Sie das Quiz zum Selbststudium aus, für das ein sicherer Prüfungsbrowser erforderlich ist.
1. Wählen Sie **SEB** herunterladen. Die Download-Seite Safe Exam Browser wird geöffnet.

   ![Eingabeaufforderung mit der Angabe, dass die Bewertung nur im sicheren Prüfungsbrowser geöffnet wird, mit den Schaltflächen SEB herunterladen und SEB starten](assets/download-or-launch-seb-prompt.png "Eingabeaufforderung mit der Angabe, dass die Bewertung nur im sicheren Prüfungsbrowser geöffnet wird, mit den Schaltflächen SEB herunterladen und SEB starten")

1. Laden Sie die entsprechende Version von Safe Exam Browser für Ihr Gerät herunter und installieren Sie diese.
1. Kehren Sie nach Abschluss der Installation zum Quiz in Adobe Learning Manager zurück.

## Abgesicherten Prüfungsbrowser starten

Starten Sie nach der Installation des sicheren Prüfungsbrowsers die Anwendung, um auf das Quiz zuzugreifen.

1. Öffnen Sie den Kurs und wählen Sie das Quiz zum Selbststudium aus, für das ein sicherer Prüfungsbrowser erforderlich ist.
1. Wählen Sie **SEB** starten.
1. Lassen Sie die erforderlichen Systemberechtigungen zu, wenn Sie dazu aufgefordert werden.
Der abgesicherte Prüfungsbrowser wird gestartet und das ausgewählte Quiz wird geöffnet.
1. Greifen Sie auf das Quiz zu und schließen Sie die Prüfung im sicheren Prüfungsbrowser ab.
   >[!NOTE]
   >
   > Wenn Sie sich bei Adobe Learning Manager über den abgesicherten Prüfungsbrowser (SEB) anmelden, können Sie nur auf Ihre zugewiesenen, nicht versuchten Quizze zugreifen, für die SEB erforderlich ist. Sie können nicht auf andere Lerninhalte zugreifen.
1. Wählen Sie **SEB** beenden.
Sie werden auf die für Ihr Konto konfigurierte Seite weitergeleitet.
