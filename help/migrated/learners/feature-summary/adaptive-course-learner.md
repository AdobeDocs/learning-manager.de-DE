# Adaptive Kurse für Teilnehmer

## Einführung

Adaptive Kurse in Adobe Learning Manager sind Kurse, die Ihnen von Ihrem Autor vermittelt werden, indem Sie Ihre Lernanforderungen messen und entsprechend Ihren Lernanforderungen anpassen, sobald diese Funktion von Ihrem Administrator aktiviert wurde. Weitere Informationen finden Sie unter [Adaptive Kurse](/help/migrated/administrators/feature-summary/adaptive-course-admin.md).

## Anpassungskurs als Teilnehmer absolvieren

Wenn Sie einen adaptiven Kurs in Adobe Learning Manager absolvieren, wird ein personalisierter Modulsatz angezeigt, der auf den Benutzergruppen basiert, zu denen Sie gehören.

### Was Sie sehen, wenn Sie einen adaptiven Kurs öffnen?

Wenn Sie einen adaptiven Kurs öffnen, sehen Sie nur die Module, die für Sie relevant sind. Module, die anderen Benutzergruppen zugewiesen sind, sind für Sie überhaupt nicht sichtbar.

Ihre Fortschrittsleiste für den Abschluss und die Anzahl der &quot;X von Y abgeschlossenen Modulen&quot; spiegeln nur Ihre erforderlichen Module wider. Ihr Kollege, der im selben Kurs eingeschrieben ist, sieht möglicherweise eine andere Anzahl von Modulen, eine andere Mischung aus erforderlichen und optionalen Modulen oder einen völlig anderen Satz von Inhalten, alle basierend auf ihren Benutzergruppen.

### Registrieren Sie sich für einen adaptiven Kurs

Die Registrierung für einen adaptiven Kurs funktioniert genauso wie die Registrierung für einen beliebigen Kurs. Sie können sich selbst im Katalog oder von Ihrem Administrator registrieren lassen.

![](assets/image_0010.png)

Wenn Sie im Kurs keine sichtbaren Module haben, die auf Ihren aktuellen Benutzergruppen basieren, können Sie sich nicht registrieren. Wenden Sie sich in diesem Fall an Ihren Administrator. Dies bedeutet wahrscheinlich, dass Ihre Benutzergruppenzuweisung aktualisiert werden muss.

### Navigieren in Modulen im Player

Wenn Sie den Kurs-Player öffnen, werden im Inhaltsverzeichnis auf der linken Seite nur die Module angezeigt, die Sie sehen können. Sie können die Navigationstasten verwenden, um nacheinander durch Ihre Module zu navigieren (bei geordneten Kursen) oder auf ein beliebiges Modul in beliebiger Reihenfolge zuzugreifen (bei ungeordneten Kursen).

Module, die zu Benutzergruppen anderer Teilnehmer gehören, werden in Ihrem Inhaltsverzeichnis nicht angezeigt.

### Ihre Abschlussanforderung verstehen

Ihr Kurs ist abgeschlossen, wenn Sie alle Module mit der Bezeichnung **Erforderlich** abgeschlossen haben. Optionale Module blockieren Ihre Fertigstellung nicht. Sie können sie beenden, erneut aufrufen oder ganz überspringen, ohne den Fortschritt in Richtung Fertigstellung zu beeinflussen.

### Was passiert, wenn ein Klassenzimmer oder eine virtuelle Klassenzimmersitzung voll ist?

Wenn ein Klassenzimmer oder ein virtuelles Klassenzimmermodul für Sie sichtbar ist, aber keine verbleibenden Lizenzen besitzt, werden Sie für den Kurs registriert und auf eine Warteliste für diese bestimmte Sitzung gesetzt. Sie können weiterhin auf alle anderen Module zugreifen und diese sofort abschließen. Nur die vollständige Sitzung wird unterbrochen.

Während Sie auf einer Sitzung auf der Warteliste stehen:

* Die Sitzung wird in Ihrem Kurs-Player angezeigt, Sie können sie jedoch nicht starten und nicht darauf zugreifen.
* Ihr Gesamtkursfortschritt wird normalerweise über Ihre anderen Module fortgesetzt.
* Sie erhalten eine Benachrichtigung, wenn eine Lizenz verfügbar wird und Sie von der Warteliste gestrichen werden.

Sobald Ihnen eine Lizenz zugewiesen wurde, wird die Sitzung zugänglich und Sie können daran teilnehmen oder sie abschließen.

### Was passiert, wenn sich Ihr Profil mitten im Kurs ändert?

Ihr adaptives Kurserlebnis ist an Ihre Benutzergruppen gebunden. Wenn sich Ihre Benutzergruppen während der Registrierung ändern, weil sich beispielsweise Ihre Rolle oder Ihr Speicherort ändert, wird Ihr Modul automatisch aktualisiert.

* Wenn Ihre aktualisierten Benutzergruppen zuvor ausgeblendete Module für Sie sichtbar machen, werden diese Module in Ihrem Kurs angezeigt. Wenn sie für Ihr neues Profil erforderlich sind, werden sie zu Ihren Abschlussanforderungen hinzugefügt.
* Wenn Ihre aktualisierten Benutzergruppen kein Modul mehr enthalten, wird es aus Ihrer Ansicht entfernt. Wenn dieses Modul zuvor erforderlich war, aber nicht mehr vorhanden ist, wird es aus der Anzahl der Abschlüsse entfernt.
* Alle Module, die Sie bereits abgeschlossen haben, bleiben als abgeschlossen markiert, auch wenn sich Ihre Benutzergruppen ändern. Sie müssen abgeschlossene Arbeiten nur wiederholen, wenn zuvor kein neu sichtbares Modul erstellt wurde.
* Ihr Startdatum, die Abschlussdaten für die fertigen Module und der gesamte Fortschrittsdatensatz bleiben bei den Profiländerungen intakt.

### Was passiert nach Abschluss des Kurses?

Wenn Sie alle erforderlichen Module abschließen, wird der Kurs als abgeschlossen markiert. Sie erhalten zu diesem Zeitpunkt alle entsprechenden Abzeichen- oder Gamification-Punkte.

Wenn sich Ihre Benutzergruppen ändern und neue erforderliche Module für Sie verfügbar sind, wird die Fertigstellung möglicherweise rückgängig gemacht und Sie müssen diese zusätzlichen Module möglicherweise abschließen.

In diesem Fall gilt Folgendes:

* Ihre ursprüngliche Fertigstellung bleibt in Ihrem Transkript als historischer Datensatz erhalten.
* Der Kurs wird in einem Status &quot;In Bearbeitung&quot; erneut geöffnet und zeigt nur die neue erforderliche Arbeit an.
* Sie müssen nur die neu erforderlichen Module abschließen.
* Sie erhalten eine Benachrichtigung, wenn eine Aktualisierung Ihrer Fertigstellung ausgelöst wird.
