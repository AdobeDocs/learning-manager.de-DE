# KI-Client mit Adobe Learning Manager verbinden

Ihr Integrationsadministrator muss die Verbindung zuerst einrichten. Wenn keine Adobe Learning Manager-Verbindung angezeigt wird, wenden Sie sich an Ihren Administrator. **Der Client ist nur für die Adobe Learning Manager Ultimate-Ebene verfügbar**.

Administratoren können auf [Adobe Learning Manager zu Ihrem AI-Client hinzufügen verweisen.](/help/migrated/administrators/feature-summary/add-alm-to-ai-client.md)

1. Öffnen Sie den AI-Client Ihres Unternehmens, z. B. Claude oder ChatGPT Enterprise.
2. Suchen Sie die Adobe Learning Manager-Verbindung in der Liste der Verbindungen.
3. Wählen Sie **Verbinden**.
4. Melden Sie sich auf Anforderung mit Ihrer Unternehmensidentität an.
5. Stellen Sie eine Frage zum Lernen. Für Ideen sehen Sie **Beispielaufforderungen für Teilnehmer**.

>[!NOTE]
>
>Sie melden sich einmal an. Anforderungen werden mit Ihren eigenen Berechtigungen ausgeführt, sodass Sie nur sehen, auf was Sie in Adobe Learning Manager zugreifen können.

## Fehlerbehebung

**Sie können die Verbindung nicht finden**

Bitten Sie Ihren Administrator, die Verbindung für Sie zu aktivieren.

**Der AI-Client erinnert sich nicht an Ihre frühere Frage**

Jede Anforderung wird als neu behandelt. Ob eine Unterhaltung fortgesetzt wird, hängt von Ihrem AI-Client ab. Wiederholen Sie die Details in Ihrer nächsten Frage.

**Der AI-Client ruft die Adobe Learning Manager-Verbindung nicht auf**

Benennen Sie die Inhalte in Ihrer Frage, z. B. Ihre Registrierungen oder ein Kursthema.
