# KI-Client mit Adobe Learning Manager verbinden

## Übersicht

Ihr Integrationsadministrator muss die Verbindung zuerst konfigurieren. Wenn keine Adobe Learning Manager-Verbindung angezeigt wird, wenden Sie sich an Ihren Administrator. **Die Verbindung ist nur für Adobe Learning Manager Ultimate -Konten verfügbar**. Administratoren können [Adobe Learning Manager zum AI-Client Ihres Unternehmens hinzufügen](/help/migrated/administrators/feature-summary/add-alm-to-ai-client.md) anzeigen.

1. Öffnen Sie den AI-Client Ihres Unternehmens, z. B. Claude oder ChatGPT Enterprise.
2. Suchen Sie die Adobe Learning Manager-Verbindung in der Liste der Verbindungen.
3. Wählen Sie **Verbinden**.
4. Authentifizieren Sie die Verbindung und geben Sie Ihre Adobe Learning Manager-Kontodetails an, wenn Sie dazu aufgefordert werden.
5. Stellen Sie eine Frage zum Lernen. Weitere Informationen zu [Beispielaufforderungen für Teilnehmer](/help/migrated/learners/feature-summary/sample-prompts-for-learners.md) finden Sie unter Ideen.

>[!NOTE]
>
>Sie authentifizieren sich einmal. Anforderungen werden mit Ihren eigenen Berechtigungen ausgeführt, sodass Sie nur sehen, auf was Sie in Adobe Learning Manager zugreifen können.

## Fehlerbehebung

**Sie können die Verbindung nicht finden.**
Bitten Sie Ihren Administrator, die Verbindung für Sie zu aktivieren.

**Der AI-Client erinnert sich nicht an Ihre frühere Frage**
Der Server behandelt jede Anforderung als neu. Ob eine Unterhaltung fortgesetzt wird, hängt von Ihrem AI-Client ab. Geben Sie die relevanten Details in Ihrer nächsten Frage erneut an.

**Der AI-Client ruft die Adobe Learning Manager-Verbindung nicht auf.**
Benennen Sie die Inhalte in Ihrer Frage, z. B. Ihre Registrierungen oder ein Kursthema.
