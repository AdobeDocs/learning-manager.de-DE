## Das Widget &quot;Von mir gespeichert&quot;

Das Widget **Von mir gespeichert** zeigt Kurse, Lernpfade, Zertifizierungen und Arbeitshilfen an, für die Sie ein Lesezeichen gesetzt haben. Dadurch finden Sie Inhalte, die Sie als gespeichert markiert haben, an einer einzigen Stelle, ohne den Katalog erneut durchsuchen zu müssen.

Nachdem ein Administrator das Widget &quot;**[!UICONTROL Gespeichert von mir]**&quot; konfiguriert hat, können Sie ein Lernobjekt (LO) speichern, indem Sie die Schaltfläche &quot;![](assets/saved-by-me-widget5.png)&quot; auswählen. Sie können ein LO auf den Seiten **[!UICONTROL Startseite]**, **[!UICONTROL Eigenes Lernen]** und **[!UICONTROL Katalog]** speichern, und gespeicherte LOs werden unter der Kategorie **[!UICONTROL Von mir gespeichert]** auf der Seite **[!UICONTROL Startseite]** angezeigt.

Sie können das Speichern eines LO aufheben, indem Sie dieselbe ![](assets/saved-by-me-widget5.png)-Schaltfläche auswählen.
