# Einstellungen

Kontoeinstellungen für Manager in Learning Manager.

Zeigen Sie Ihre Profilinformationen an, fügen Sie ein Profilfoto hinzu bzw. ändern Sie es und ändern Sie den Inhalt, der unter **Über mich** angezeigt wird.

## Kontoeinstellungen {#accountsettings}

1. Klicken Sie in der rechten oberen Ecke neben Ihrem Foto/Konto auf die Dropdownliste und wählen Sie dann **Profileinstellungen**.
1. Im Popupfenster können Sie ein Foto hinzufügen bzw. es ändern, indem Sie mit der Maus darauf zeigen und im Bereich „Profilfoto“ auf **Bearbeiten** klicken.
1. Fügen Sie unter „Über mich“ Inhalte hinzu bzw. ändern Sie sie, indem Sie auf den darunter befindlichen Textbereich klicken.
1. Klicken Sie auf **[!UICONTROL Speichern]**.
